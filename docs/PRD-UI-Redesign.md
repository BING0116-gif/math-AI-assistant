# 前端UI重构PRD - Apple风格简约高级设计

## 1. 产品背景

### 1.1 现状分析
当前数学AI助手前端界面存在以下问题：
- 使用紫色主题，视觉风格偏年轻化，缺乏专业感
- 过度使用渐变、发光阴影、动画效果，显得杂乱
- 配色不统一，多种强调色混用
- 与产品定位（数学学习工具）不够匹配

### 1.2 重构目标
打造一个**简约、高级、专业**的界面，参考Apple设计语言：
- 极简留白，让内容说话
- 单一蓝色强调色，视觉统一
- 无装饰性渐变和发光效果
- 流畅自然的交互动画

## 2. 设计理念

### 2.1 核心原则
| 原则 | 说明 |
|------|------|
| **留白优先** | 大面积留白，给内容呼吸空间 |
| **单一强调** | 仅使用一个品牌蓝色(#0066cc)作为交互色 |
| **克制阴影** | 仅在必要时使用极淡阴影 |
| **自然动效** | 动画流畅自然，不炫技 |
| **内容至上** | UI退居幕后，让数学内容成为主角 |

### 2.2 参考标准
基于 [Apple DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md) 设计系统

## 4. 组件设计规范

### 4.1 侧边栏 (Sidebar)

**设计要求**：
- 纯白背景，右侧极细边框分隔
- 品牌区域简洁，无渐变图标
- 历史对话列表项悬停时背景微变
- 当前选中项使用浅蓝色背景
- 底部按钮使用线框样式

**交互规范**：
- 悬停：背景变为 `#f5f5f7`
- 选中：背景变为 `rgba(0, 102, 204, 0.08)`
- 过渡动画：0.2s ease

### 4.2 顶部导航 (TopBar)

**设计要求**：
- 高度 52px
- 半透明背景 + 毛玻璃效果
- 底部细边框
- 菜单图标简洁线条

### 4.3 英雄区 (WelcomeHero)

**设计要求**：
- 大面积留白，上下 padding 各 80px
- 标题 56px，字重 600，字间距 -0.28px
- 副标题 21px，字重 400，颜色 `#86868b`
- 无浮动动画，仅淡入效果

### 4.4 功能卡片 (FeatureCards)

**设计要求**：
- 白色背景，1px 边框 `#e0e0e0`
- 圆角 18px
- 悬停时：轻微上浮(translateY -4px) + 阴影加深
- 无背景色变化，无边框颜色变化

### 4.5 输入框 (ChatInput)

**设计要求**：
- 白色背景，1px 边框
- 圆角 18px
- 聚焦时：边框变为蓝色，无发光效果
- 发送按钮：蓝色胶囊形状

### 4.6 消息气泡 (MessageItem)

**设计要求**：
- 用户消息：浅蓝色背景 `rgba(0, 102, 204, 0.08)`
- AI消息：无背景，直接显示内容
- 圆角 18px
- 间距 24px

## 6. 交互规范

### 6.1 按钮状态

| 状态 | 样式 |
|------|------|
| 默认 | 蓝色背景，白色文字 |
| 悬停 | 背景变亮 `#0071e3` |
| 按下 | 背景变暗 `#004499`，轻微缩小 |
| 禁用 | 透明度 0.4 |

### 6.2 过渡动画

```css
/* 标准过渡 */
transition: all 0.3s cubic-bezier(0.25, 0.1, 0.25, 1);

/* 快速过渡 */
transition: all 0.2s cubic-bezier(0.25, 0.1, 0.25, 1);
```

### 6.3 悬停效果

- 卡片：上浮 4px + 阴影加深
- 按钮：背景色变化
- 链接：颜色变亮

## 7. 深色模式

### 7.1 色彩映射

| 亮色模式 | 深色模式 |
|----------|----------|
| `#ffffff` 背景 | `#000000` 背景 |
| `#f5f5f7` 次级背景 | `#1c1c1e` 次级背景 |
| `#1d1d1f` 文字 | `#ffffff` 文字 |
| `#86868b` 次要文字 | `#cccccc` 次要文字 |

### 7.2 特殊处理

- 顶部导航使用半透明黑色 + 毛玻璃
- 边框使用 `rgba(255, 255, 255, 0.08)`
- 阴影在深色模式下适当加强

## 8. 验收标准

### 8.1 视觉验收

- [ ] 主色调为单一蓝色 `#0066cc`
- [ ] 背景以白色/灰白为主
- [ ] 无渐变背景
- [ ] 无发光阴影效果
- [ ] 文字使用近黑色 `#1d1d1f` 而非纯黑
- [ ] 整体留白充足

### 8.2 交互验收

- [ ] 所有按钮有完整的状态反馈
- [ ] 悬停动画流畅自然
- [ ] 过渡时间统一为 0.2-0.3s
- [ ] 深色模式切换正常

### 8.3 响应式验收

- [ ] 桌面端 (≥1024px)：侧边栏固定显示
- [ ] 平板端 (768px-1023px)：侧边栏可收起
- [ ] 移动端 (<768px)：侧边栏隐藏，汉堡菜单触发
