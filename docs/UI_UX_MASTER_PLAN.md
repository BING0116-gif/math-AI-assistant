# 知微 Math AI · 前端体验与知识图谱设计总纲

> 版本：Concept 1.0 · 2026-08-04  
> 目标：把现有“通用 AI 聊天工具”升级为具有独立品牌辨识度的“数学认知工作台”。

## 1. 核心结论

推荐采用 **Editorial Intelligence（编辑部式智能）+ Cognitive Canvas（认知画布）** 的双表面系统：

- 阅读、对话、学习计划使用暖灰白界面，降低长期阅读疲劳。
- 知识图谱、推演过程、关系探索使用墨蓝黑画布，突出节点和连接。
- 两种表面共享相同的侧栏、按钮、字体、圆角、状态色和动效，因此不是“两个网站”。
- 产品核心不是“展示一个图”，而是把 **提问 → 概念定位 → 路径学习 → 练习验证 → 错题复盘 → 掌握度更新** 串成闭环。

不建议全站做纯黑色。数学学习含大量长文本、公式和步骤，纯暗色会降低连续阅读的舒适度；深色应被用于需要空间感和关系聚焦的图谱画布，以及可选的全局暗色模式。

## 2. 现状审计

### 值得保留

- `home-concept.html` 的暖白纸张感、编辑式标题和克制的留白，已经比通用 SaaS 首页更有气质。
- 现有 Vue 前端具备聊天、课程目录、知识点学习、错题本、公式渲染和 3D 图谱基础。
- `KnowledgeGalaxy.vue` 已具备旋转、缩放、点击节点和标签投影，可继续作为“沉浸式总览”的技术原型。

### 拉低质感的原因

1. **视觉语言冲突**：通用靛紫 SaaS、金色编辑风、蓝黑星空、玻璃拟态同时存在。
2. **语义色混乱**：紫色既代表品牌、按钮、课程节点，也承担选中态；橙色既是知识点又是警告。
3. **组件形态不统一**：圆角从 6px 到 32px、虚线按钮、发光阴影、渐变卡片混用。
4. **图谱只有层级，没有学习语义**：节点颜色表达类型，却没有明确表达掌握、学习中、薄弱、锁定。
5. **自动旋转抢夺控制权**：知识图谱首先是工作界面，不是背景动画；默认持续旋转会增加定位成本。
6. **侧栏偏聊天历史**：产品的核心学习对象（今日计划、课程地图、错题、收藏）被压缩到页脚。
7. **结构图不等于知识图谱**：课程树适合查看章节层级；前置依赖、相似概念、易混点和题型关系需要真正的关系图。
8. **细节不专业**：仍有 emoji 作为结构图标、原生 `prompt/confirm`、部分按钮没有完整的 loading/disabled/focus 状态。

## 3. 品牌定位与风格

### 关键词

**理性、克制、可信、耐读、可探索、有温度。**

### 视觉比喻

- 浅色区像一本被认真做过批注的数学书。
- 深色图谱像安静的天文台，而不是霓虹游戏 HUD。
- Agent 像导师和研究搭档，而不是会说话的搜索框。

### 避免

- 大面积赛博紫、强辉光、玻璃卡片叠满全屏。
- 每张卡片一个渐变、每个按钮都浮起、无意义的自动动画。
- 用颜色代替文本标签；用节点大小夸张装饰而不表达数据。
- 首页堆六到八个等权功能入口，让用户自己决定学习路径。

## 4. 设计令牌

### 4.1 浅色工作台

| 语义 | 色值 | 用途 |
|---|---:|---|
| Canvas | `#F4F2EC` | 页面底色 |
| Surface | `#FBFAF6` | 卡片、输入区 |
| Surface strong | `#FFFFFF` | 浮层、选中面板 |
| Ink | `#20231F` | 主文字、主按钮 |
| Ink secondary | `#666B63` | 说明文字 |
| Border | `#DDDCD4` | 分隔与描边 |
| Agent teal | `#2D6B5F` | Agent 行为、主进度 |
| Knowledge violet | `#6E63A6` | 概念、公式、知识关系 |
| Review amber | `#B8743B` | 待复习、注意 |

### 4.2 深色认知画布

| 语义 | 色值 | 用途 |
|---|---:|---|
| Graph canvas | `#0B1110` | 图谱背景，不用纯黑 |
| Graph surface | `#121A18` | 工具栏、检查器 |
| Graph grid | `#21302C` | 极弱网格 |
| Graph text | `#EDF1EC` | 节点标签主文字 |
| Graph muted | `#8E9A94` | 次级标签 |
| Graph edge | `#50605A` | 默认连线 |
| Graph selected | `#D8C57A` | 当前选中与主路径 |

### 4.3 节点状态优先于学科颜色

不要让十几个学科各占一种高饱和颜色。先用状态表达学习含义，再用小图标或边框纹理表达节点类型。

| 学习状态 | 颜色 | 视觉规则 |
|---|---:|---|
| 已掌握 | `#62A789` | 实心、低辉光、显示勾选 |
| 学习中 | `#D8C57A` | 金色双环、呼吸只出现一次 |
| 未学习 | `#66736D` | 中性灰绿、降低饱和度 |
| 薄弱点 | `#D9826B` | 珊瑚色描边 + 警示图标，不能只靠红色 |
| 当前推荐 | `#8B82C8` | 紫罗兰外环 + “下一步”标签 |
| 锁定/缺前置 | `#3A4541` | 虚线边框 + 锁图标 |

节点类型用形态补充：概念为圆角矩形，公式为菱形/公式图标，题型为六边形或题卡图标，章节仅作为可折叠分组边界。

## 5. 字体、尺寸与质感

- 中文正文：`Noto Sans SC` / 系统无衬线；英文与数字可用 `Inter`。
- 品牌标题：`Newsreader` + `Noto Serif SC`，只用于首页标题和章节大标题。
- 公式：KaTeX 字体；数值和快捷键：`DM Mono` / `JetBrains Mono`。
- 基础字号 15–16px，正文行高 1.65；小标签不低于 12px。
- 圆角只保留 10 / 14 / 20px 三档；胶囊仅用于状态和筛选。
- 主要靠边框和表面明度区分层级，阴影只用于悬浮层和当前聚焦对象。
- 动效 160–240ms；图谱镜头移动 320–420ms；尊重 `prefers-reduced-motion`。

## 6. 全局信息架构

### 一级导航

1. **今日**：下一步行动、学习节奏、最近进度。
2. **提问**：Agent 对话与多模态题目输入。
3. **知识图谱**：课程层级、概念关系、掌握状态、推荐路径。
4. **学习路径**：目标、阶段、任务清单和测验。
5. **错题复盘**：错因、相似题、遗忘曲线和再测。
6. **资料库**：公式、定理、笔记、上传资料和引用来源。

“新推演”是全局主动作，固定在侧栏顶部；对话历史折叠为二级区域，不再占据大部分导航空间。

### 全局命令入口

- `⌘/Ctrl + K`：搜索概念、公式、题目、历史对话和功能。
- `N`：新推演。
- `/`：在图谱中搜索节点。
- `F`：聚焦选中节点；`Esc`：清除选择或关闭面板。

## 7. 核心页面

### 7.1 今日工作台

首页只回答三个问题：

1. 我现在最应该做什么？
2. 我的知识网络发生了什么变化？
3. 我可以怎样快速开始？

首屏由“主提问框 + 今日推荐任务 + 图谱进度切片”构成。功能卡降级到次屏，避免工具陈列馆。

### 7.2 Agent 对话

- 桌面端采用 3 区结构：导航 / 对话正文 / 可收起的上下文检查器。
- 检查器显示“本轮识别的知识点、使用资料、当前学习目标、加入图谱的变化”。
- 回答结构固定为：结论、关键推理、逐步推导、检查、下一步，而不是一整块 Markdown。
- 每条关键结论可执行：`加入笔记`、`标记没懂`、`生成变式`、`定位到图谱`。
- 工具执行使用可折叠时间线，显示状态和结果；不展示冗长内部推理。

### 7.3 知识图谱

建议做成双视图：

- **课程地图（2D）**：默认视图。稳定、可读，适合查找前置关系、规划路径和键盘操作。
- **星系总览（3D）**：可选的沉浸视图，用于全局感知，不承担精确学习操作。

标准布局：

- 顶部：搜索、视图切换、筛选、图例、适应屏幕。
- 中央：全屏深色画布。
- 右侧检查器：概念摘要、掌握度、前置概念、关联题型、最近错误、CTA。
- 底部路径带：显示“当前位置 → 推荐下一步 → 目标”。

选中节点时，只高亮一跳邻居和当前推荐路径，其余节点降至 20–30% 明度，避免信息噪声。

### 7.4 学习空间

不再只用 Tabs 罗列“概念 / 公式 / 例题 / 练习”。改为可完成的学习任务流：

1. 先验检测（1–3 题）。
2. 核心概念与直觉。
3. 公式推导与可视化。
4. Worked example。
5. 渐隐脚手架练习。
6. Exit ticket，结果回写图谱。

右侧显示当前节点在图谱中的局部邻域，随学习进度更新。

### 7.5 错题复盘

- 默认按“错因”而不是题目时间排序：概念不清、条件遗漏、公式误用、计算错误、策略选择。
- 每个错题必须关联知识点、题型、掌握度变化和下次复习时间。
- 支持“一键生成同错因变式”和“回到对应图谱节点”。

## 8. 按钮与组件规则

### 按钮层级

- Primary：每个视图最多一个，深墨色或 Agent teal 实心，如“继续学习”。
- Secondary：浅色描边，如“查看图谱”。
- Tertiary：无容器文本按钮，如“稍后处理”。
- Icon：40×40px 可见容器，实际点击区不小于 44×44px，必须有 `aria-label`。
- Danger：只用于删除、清空等不可逆动作；确认层提供清晰对象名称和后果。

所有按钮必须提供 default / hover / pressed / focus / loading / disabled 六态。禁用态不能只有颜色变淡，还需语义属性。

### 关键组件

- `AppShell`：统一侧栏、顶栏、移动端底栏。
- `AgentComposer`：文本、图片、文件、语音、推演模式和发送状态。
- `KnowledgeNode`：节点类型、学习状态、掌握度和选中态。
- `ConceptInspector`：右侧详情面板，桌面 360–400px，移动端 bottom sheet。
- `LearningPathRail`：路径节点、前置阻塞和完成态。
- `ToolRunTimeline`：工具调用过程与结果。
- `MasteryRing`：掌握度必须同时显示数字/标签，不能只有环形颜色。
- `EmptyState` / `ErrorState` / `Skeleton`：统一文案、恢复动作和可访问性。

## 9. 响应式策略

- ≥ 1280px：固定 248px 侧栏 + 主工作区 + 可选 380px 检查器。
- 768–1279px：侧栏收窄为 72px 图标轨；检查器覆盖或抽屉。
- < 768px：底部 4 项主导航；图谱详情使用 bottom sheet；工具栏收进“视图设置”。
- 手机端不直接缩放桌面图谱：默认显示“聚焦节点 + 一跳关系”，支持逐层展开。

## 10. 技术建议

当前项目是 Vue 3 + Vite + Element Plus + Three.js，建议渐进升级，不需要推倒重写。

### 图谱技术选择

- **默认 2D 学习图谱**：优先评估 Cytoscape.js。它适合关系图、选择器、布局和图分析，且与 Vue 容易封装。
- **超大规模总览（上千节点）**：Sigma.js + Graphology，WebGL 性能更合适。
- **可编辑流程/手工布置节点**：Vue 生态可评估 Vue Flow；React Flow 本身不适合直接引入现有 Vue 项目。
- **现有 Three.js**：保留为 3D 星系总览，默认关闭自动旋转，并增加键盘/列表替代视图。

开源参考：

- Open WebUI：参考成熟 AI 对话的信息密度、工具入口和响应式结构。
- Hugging Face Chat UI：参考简洁的对话主体与模型状态表达。
- Sage Wiki：参考知识库、引用和关系图在同一产品中的组织方式。
- Cytoscape.js：2D 关系图与分析能力。
- Sigma.js：大规模 WebGL 图谱。
- xyflow：参考节点编辑器的工具条、MiniMap 和节点交互，但不要直接照搬其 React 实现。
- Logseq：参考局部图谱与知识条目之间的往返导航。

### 工程治理

- 新建 `tokens.css`，只暴露语义令牌；逐步清除组件内硬编码颜色。
- Element Plus 只保留表单、弹层、日期等复杂组件，并通过统一主题变量包装。
- 图标统一为 Lucide 或 Phosphor，移除结构性 emoji。
- 建立 Storybook/Histoire 组件状态页与 Playwright 视觉回归。
- 对话长列表虚拟化；Three/Sigma 图谱按路由懒加载；避免首页加载 WebGL。

## 11. 功能开发路线图

### Phase 0 · 设计基础（1–2 周）

- 统一 tokens、字体、图标、按钮、输入、卡片、弹层、空状态。
- 重构 AppShell 和导航；保留现有业务逻辑。
- 建立 375 / 768 / 1024 / 1440 四档视觉回归。

**验收**：首页、对话、图谱三页看起来属于同一产品；无结构性 emoji；键盘焦点完整。

### Phase 1 · 核心闭环（2–4 周）

- 新首页与 Agent Composer。
- 2D 课程地图、节点检查器、局部高亮、搜索与筛选。
- “回答定位到知识点”“从知识点生成练习”“错题回写掌握度”。

**验收**：用户能从一道题进入图谱，再完成一次针对性练习并看到节点状态变化。

### Phase 2 · 个性化学习（3–5 周）

- 掌握度模型、前置依赖、推荐下一步。
- 错因分类、变式训练、间隔复习队列。
- 学习路径目标与阶段进度。

**验收**：推荐动作可解释，用户能看到“为什么推荐这个节点”。

### Phase 3 · Agent 工作台（3–5 周）

- 工具运行时间线、上下文检查器、资料引用。
- 用户笔记/资料与课程图谱关联。
- 图谱差异提示：本轮对话新增、加强或暴露薄弱的节点。

**验收**：Agent 的动作、资料来源和知识状态变化可见、可撤销。

### Phase 4 · 高级探索（按需）

- 3D 星系总览、时间维度回放、班级/教师视图。
- 图谱导入导出、协作注释、分享学习路径。
- 仅在真实数据量和使用场景证明价值后建设。

## 12. 关键指标

- 首次提问完成率、首个学习闭环完成率。
- 从回答跳转到图谱/学习空间的比例。
- 推荐下一步接受率与完成率。
- 错题二次测试正确率、7/30 天概念保持率。
- 图谱搜索成功率、选中节点后有效动作率。
- 可用性：键盘可达率、WCAG AA 对比度、核心视图 LCP/INP。

## 13. 本轮原型范围

`math-ai-assistant.design/pages/home-graph-concept.html` 展示的是统一后的“今日工作台”方向：

- 保留旧稿的编辑式温度和品牌感。
- 把知识图谱变成首页的一等公民，而不是藏在功能卡里。
- 用同一组青绿、紫罗兰、金色把浅色卡片和深色画布连接起来。
- 展示主按钮、次按钮、状态标签、导航、学习任务和图谱节点的统一规则。

它是视觉与信息架构基线，不直接替换当前 Vue 页面。确认方向后，再按 Phase 0–1 落到组件和真实数据。
