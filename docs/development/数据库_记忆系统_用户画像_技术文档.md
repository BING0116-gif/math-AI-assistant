## 一、系统概述

### 1.1 系统目标

构建一个**高性能、高可用、强扩展**的数据管理子系统，为数学 AI Agent 提供：

- **持久化存储**：用户数据、学习记录、题库内容的可靠存储
- **智能记忆**：跨会话的上下文保持和个性化记忆检索
- **画像分析**：多维度的学习行为分析和个性化推荐支撑

### 1.2 核心设计原则

| 原则 | 实现方式 | 目标指标 |
|------|---------|---------|
| **强扩展性** | 分层架构 + 接口抽象 + 水平分片 | 支持 10x 数据量无缝扩展 |
| **安全性** | 加密存储 + 访问控制 + 审计日志 | 符合 GDPR/等保要求 |
| **低延迟** | 读写分离 + 缓存优化 + 索引设计 | P99 < 50ms（单表查询） |
| **高效性** | 连接池 + 批处理 + 异步IO | QPS > 1000（写操作） |

### 1.3 技术选型对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| **SQLite** (推荐开发) | 零配置、单文件、嵌入式 | 并发写入限制 | 开发/测试/小规模部署 |
| **PostgreSQL** (推荐生产) | 功能强大、JSONB支持、扩展性好 | 运维复杂度较高 | 生产环境/大规模数据 |
| **MySQL** | 生态成熟、性能稳定 | JSON支持较弱 | 传统Web应用 |
| **MongoDB** | 文档模型灵活、水平扩展好 | 事务支持弱 | 日志/非结构化数据 |

**推荐组合**: SQLite (开发) → PostgreSQL (生产) + Redis (缓存)

### 2.2 分层职责说明

#### 应用层 (Application Layer)
- **职责**: 处理 HTTP 请求、参数验证、响应格式化
- **技术栈**: FastAPI Router + Pydantic Models
- **性能要求**: P99 < 100ms

#### 业务逻辑层 (Business Logic Layer)
- **职责**: 核心业务规则、数据处理、算法实现
- **关键模块**:
  - `MemoryManager`: 记忆存储、检索、关联分析
  - `UserProfileAnalyzer`: 画像计算、维度分析、趋势预测
  - `LearningAnalytics`: 统计聚合、报告生成、可视化数据
- **设计模式**: Strategy + Observer + Repository

#### 数据访问层 (Data Access Layer)
- **职责**: 数据库 CRUD 操作、查询优化、事务管理
- **核心组件**:
  - `BaseRepository`: 泛型仓储基类
  - `QuestionRepository`: 题库操作
  - `LearningRecordRepository`: 学习记录操作
  - `SessionRepository`: 会话历史操作
- **ORM框架**: SQLAlchemy 2.0 (async)

#### 存储层 (Storage Layer)
- **PostgreSQL**: 主数据库（结构化数据）
- **Redis**: 缓存层（热点数据）
- **文件系统**: 非结构化数据（图片、导出文件）

### 3.2 核心数据模型定义

#### 3.2.1 用户模型 (User)

```python
from sqlalchemy import Column, String, DateTime, Integer, Boolean, Text, JSON
from sqlalchemy.dialects.postgresql import UUID
from sqlalchemy.orm import DeclarativeBase, relationship
from datetime import datetime
import uuid


class Base(DeclarativeBase):
    """声明式基类"""
    pass


class User(Base):
    """
    用户模型 - 存储用户基本信息和偏好设置
    
    安全性设计：
    - 密码使用 bcrypt 哈希存储（不可逆）
    - 支持双因素认证（可选）
    - 记录最后登录时间和IP
    """
    __tablename__ = "users"
    
    # 主键：使用 UUID 防止枚举攻击
    id = Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    
    # 基本信息
    username = Column(String(50), unique=True, nullable=False, index=True)
    email = Column(String(255), unique=True, nullable=False, index=True)
    password_hash = Column(String(255), nullable=False)  # bcrypt hash
    
    # 角色权限
    role = Column(String(20), default="student")  # student / teacher / admin
    is_active = Column(Boolean, default=True)
    is_verified = Column(Boolean, default=False)  # 邮箱验证状态
    
    # 学习偏好（JSON 字段，灵活扩展）
    preferences = Column(JSON, default=dict)  # {"difficulty_mode": "adaptive", ...}
    
    # 安全审计字段
    last_login_at = Column(DateTime(timezone=True))
    last_login_ip = Column(String(45))  # IPv6 兼容
    failed_login_count = Column(Integer, default=0)
    locked_until = Column(DateTime(timezone=True))
    
    # 时间戳
    created_at = Column(DateTime(timezone=True), default=datetime.utcnow)
    updated_at = Column(DateTime(timezone=True), onupdate=datetime.utcnow)
    
    # 关系
    sessions = relationship("ChatSession", back_populates="user", lazy="dynamic")
    learning_records = relationship("LearningRecord", back_populates="user", lazy="dynamic")
    exam_papers = relationship("ExamPaper", back_populates="user", lazy="dynamic")
```

#### 3.2.2 学习记录模型 (LearningRecord)

```python
class LearningRecord(Base):
    """
    学习记录模型 - 记录每次交互的详细信息
    
    设计要点：
    - 支持多种事件类型（提问/作答/复习/浏览）
    - 记录工具调用链路（用于分析解题路径）
    - 支持细粒度的错误分类
    """
    __tablename__ = "learning_records"
    
    id = Column(Integer, primary_key=True, autoincrement=True)
    
    # 外键关联
    user_id = Column(UUID(as_uuid=True), ForeignKey("users.id"), nullable=False, index=True)
    question_id = Column(String(20), ForeignKey("questions.id"), nullable=True, index=True)
    
    # 关系
    user = relationship("User", back_populates="learning_records")
    question = relationship("Question", back_populates="learning_records")
    
    # 事件信息
    event_type = Column(String(30), nullable=False, index=True)
    # 类型枚举: "ask" | "answer_correct" | "answer_wrong" | "review" | "skip" | "hint_request"
    
    # 问题上下文
    question_content = Column(Text, nullable=False)
    category = Column(String(50), nullable=False, index=True)
    sub_categories = Column(String(200))  # 逗号分隔
    difficulty = Column(Integer, default=3)  # 1-5
    
    # 作答信息
    user_answer = Column(Text)
    correct_answer = Column(Text)
    is_correct = Column(Boolean, default=None)  # NULL 表示未作答
    
    # 性能指标
    time_spent = Column(Integer)  # 秒
    hint_count = Column(Integer, default=0)
    tools_used = Column(String(200))  # 逗号分隔的工具列表
    
    # 错误分析
    error_category = Column(String(50))
    # 错误类型: "calculation_error" | "concept_misunderstanding" | "careless" | ...
    error_reason = Column(Text)
    correction_suggestion = Column(Text)
    
    # 元数据（灵活扩展）
    metadata_ = Column("metadata", JSON, default=dict)
    # 示例: {"session_id": "...", "source": "chat/practice/exam", ...}
    
    # 时间戳
    created_at = Column(DateTime(timezone=True), default=datetime.utcnow, index=True)
    
    # 索引优化（复合索引）
    __table_args__ = (
        Index('idx_learning_user_category', 'user_id', 'category'),
        Index('idx_learning_user_time', 'user_id', 'created_at'),
        Index('idx_learning_event_type', 'event_type', 'created_at'),
    )
```

#### 3.2.3 题库模型 (Question)

```python
class Question(Base):
    """
    题目模型 - 支持多种题型和来源
    
    扩展性设计：
    - 使用 JSON 字段存储选项和标签（灵活）
    - 支持 LaTeX 格式的题目内容
    - 记录来源和版本信息
    """
    __tablename__ = "questions"
    
    id = Column(String(20), primary_key=True)  # 自定义短ID
    
    # 题目内容
    content = Column(Text, nullable=False)  # 支持 LaTeX
    question_type = Column(String(30), nullable=False, index=True)
    # 枚举: "choice" | "fill_blank" | "calculation" | "proof" | "application"
    
    # 选择题选项（JSON 数组）
    options = Column(JSON)  # [{"label": "A", "content": "..."}, ...]
    
    # 答案与解析
    answer = Column(Text, nullable=False)
    analysis = Column(Text)  # 详细解析
    solution_steps = Column(JSON)  # 分步解答 [{"step": 1, "content": "..."}]
    
    # 分类标注
    category = Column(String(50), nullable=False, index=True)
    sub_categories = Column(String(200))
    knowledge_points = Column(String(500))  # 逗号分隔的知识点列表
    
    # 难度与复杂度
    difficulty = Column(Integer, default=3, index=True)  # 1-5
    complexity_score = Column(Float)  # 0-1 的综合复杂度评分
    
    # 来源与版本
    source = Column(String(100))  # 来源标识（如"2025期末试卷"）
    source_url = Column(String(500))  # 原始链接
    version = Column(Integer, default=1)
    
    # 标签与属性
    tags = Column(String(500))  # 逗号分隔
    is_active = Column(Boolean, default=True, index=True)
    estimated_time = Column(Integer, default=3)  # 预估分钟数
    
    # 使用统计（冗余但加速查询）
    usage_count = Column(Integer, default=0)  # 被使用次数
    correct_rate = Column(Float, default=0.0)  # 全局正确率
    avg_time_spent = Column(Float, default=0.0)  # 平均用时
    
    # 时间戳
    created_at = Column(DateTime(timezone=True), default=datetime.utcnow)
    updated_at = Column(DateTime(timezone=True), onupdate=datetime.utcnow)
    
    # 关系
    learning_records = relationship("LearningRecord", back_populates="question", lazy="dynamic")
    
    __table_args__ = (
        Index('idx_question_category_difficulty', 'category', 'difficulty'),
        Index('idx_question_source', 'source'),
    )
```

```python
class ChatSession(Base):

                           order_by="ChatMessage.created_at",

    # Agent 配置（记录会话使用的策略）

    tools_used = Column(String(200))
    
    created_at = Column(DateTime(timezone=True), default=datetime.utcnow, index=True)
    updated_at = Column(DateTime(timezone=True), onupdate=datetime.utcnow)
```

### 4.2 记忆类型定义

#### 4.2.1 短期记忆 (Short-TermMemory)

```python
from dataclasses import dataclass, field
from typing import List, Dict, Any, Optional
from datetime import datetime, timedelta
import hashlib
import json


@dataclass
class MemoryItem:
    """记忆项 - 通用的记忆单元"""
    id: str
    content: str  # 记忆内容（文本或JSON字符串）
    memory_type: str  # "fact" | "preference" | "event" | "error" | "insight"
    category: str  # 知识点分类
    importance: float = 0.5  # 重要程度 0-1
    created_at: datetime = field(default_factory=datetime.now)
    last_accessed: datetime = field(default_factory=datetime.now)
    access_count: int = 0
    ttl_seconds: int = 3600  # 生存时间（秒），0表示永不过期
    metadata: Dict[str, Any] = field(default_factory=dict)
    
    @property
    def is_expired(self) -> bool:
        if self.ttl_seconds == 0:
            return False
        return datetime.now() > self.created_at + timedelta(seconds=self.ttl_seconds)
    
    @property
    def signature(self) -> str:
        """生成内容签名（用于去重）"""
        return hashlib.md5(
            f"{self.category}:{self.content[:100]}".encode()
        ).hexdigest()[:16]


@dataclass
class ShortTermMemory:
    """
    短期记忆 - 当前会话的临时存储
    
    特点：
    - 容量有限（默认最近 50 条）
    - 自动过期（TTL 机制）
    - 快速读写（内存优先）
    """
    capacity: int = 50
    default_ttl: int = 1800  # 30分钟
    items: List[MemoryItem] = field(default_factory=list)
    
    def add(self, item: MemoryItem) -> None:
        """添加记忆项（自动淘汰过期项）"""
        if item.ttl_seconds == 0:
            item.ttl_seconds = self.default_ttl
        
        # 检查重复
        existing = self.find_by_signature(item.signature)
        if existing:
            existing.last_accessed = datetime.now()
            existing.access_count += 1
            return
        
        # 淘汰过期项
        self._cleanup_expired()
        
        # 容量检查
        if len(self.items) >= self.capacity:
            self._evict_lru()
        
        self.items.append(item)
    
    def find_by_signature(self, signature: str) -> Optional[MemoryItem]:
        for item in self.items:
            if item.signature == signature:
                return item
        return None
    
    def retrieve(self, query: str, top_k: int = 5) -> List[MemoryItem]:
        """
        检索相关记忆（基于关键词匹配）
        
        Args:
            query: 查询文本
            top_k: 返回数量
        
        Returns:
            相关记忆列表（按相关性排序）
        """
        query_lower = query.lower()
        query_words = set(query_lower.split())
        
        scored_items = []
        for item in self.items:
            if item.is_expired:
                continue
            
            # 简单的关键词重叠度计算
            content_lower = item.content.lower()
            content_words = set(content_lower.split())
            
            overlap = len(query_words & content_words)
            union = len(query_words | content_words)
            jaccard = overlap / union if union > 0 else 0
            
            # 类别匹配加分
            category_bonus = 0.3 if item.category in query else 0
            
            # 访问频率加权
            recency_weight = 1.0 / (1.0 + item.access_count * 0.1)
            
            final_score = jaccard + category_bonus * recency_weight
            
            scored_items.append((item, final_score))
        
        # 按得分排序，返回 Top-K
        scored_items.sort(key=lambda x: x[1], reverse=True)
        result = [item for item, _ in scored_items[:top_k]]
        
        # 更新访问时间
        for item in result:
            item.last_accessed = datetime.now()
            item.access_count += 1
        
        return result
    
    def _cleanup_expired(self) -> int:
        """清理过期项"""
        before = len(self.items)
        self.items = [item for item in self.items if not item.is_expired]
        return before - len(self.items)
    
    def _evict_lru(self) -> None:
        """淘汰最久未访问的项（LRU 策略）"""
        if not self.items:
            return
        lru_item = min(self.items, key=lambda x: x.last_accessed)
        self.items.remove(lru_item)
    
    def clear(self) -> None:
        """清空所有短期记忆"""
        self.items.clear()
    
    @property
    def stats(self) -> Dict[str, Any]:
        return {
            "total_items": len(self.items),
            "expired_count": sum(1 for i in self.items if i.is_expired),
            "capacity_usage": f"{len(self.items)}/{self.capacity}",
            "types_distribution": {
                t: sum(1 for i in self.items if i.memory_type == t)
                for t in set(i.memory_type for i in self.items)
            }
        }
```

#### 4.2.2 长期记忆 (LongTermMemory)

```python
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select, func, and_, or_
from typing import List, Dict, Any, Optional


class LongTermMemory:
    """
    长期记忆 - 持久化的用户学习数据
    
    特点：
    - 存储在数据库中（跨会话保持）
    - 支持复杂的关联查询
    - 提供聚合分析和趋势计算
    """
    
    def __init__(self, db_session: AsyncSession):
        self.db = db_session
    
    async def get_user_profile(self, user_id: str) -> Dict[str, Any]:
        """
        获取用户学习画像（聚合视图）
        
        Returns:
            {
                "total_questions": 150,
                "correct_rate": 0.72,
                "avg_time_per_question": 45.3,
                "weak_points": [
                    {"category": "定积分", "mastery": 0.55, "count": 25},
                    ...
                ],
                "strong_points": ["导数", "极限"],
                "recommended_difficulty": 4,
                "learning_streak": 7,
                "active_hours": ["19:00-22:00"],
                "recent_activity": [...]
            }
        """
        from .models import LearningRecord
        
        # 1. 基础统计
        total_result = await self.db.execute(
            select(func.count()).select_from(LearningRecord).where(
                LearningRecord.user_id == user_id
            )
        )
        total_questions = total_result.scalar() or 0
        
        correct_result = await self.db.execute(
            select(func.count()).select_from(LearningRecord).where(
                and_(
                    LearningRecord.user_id == user_id,
                    LearningRecord.is_correct == True
                )
            )
        )
        correct_count = correct_result.scalar() or 0
        
        correct_rate = correct_count / total_questions if total_questions > 0 else 0
        
        # 2. 平均用时
        avg_time_result = await self.db.execute(
            select(func.avg(LearningRecord.time_spent)).where(
                and_(
                    LearningRecord.user_id == user_id,
                    LearningRecord.time_spent.isnot(None)
                )
            )
        )
        avg_time = avg_time_result.scalar() or 0
        
        # 3. 薄弱点分析（按知识点分组）
        weak_query = select(
            LearningRecord.category,
            func.count().label("total"),
            func.sum(func.cast(LearningRecord.is_correct, Integer)).label("correct"),
        ).where(
            LearningRecord.user_id == user_id
        ).group_by(LearningRecord.category).having(
            func.count() >= 3  # 至少3次记录才纳入分析
        ).order_by("correct / total ASC")  # 按正确率升序
        
        weak_result = await self.db.execute(weak_query)
        weak_rows = weak_result.all()
        
        weak_points = []
        for row in weak_rows:
            mastery = row.correct / row.total if row.total > 0 else 0
            if mastery < 0.7:  # 只显示薄弱点
                weak_points.append({
                    "category": row.category,
                    "mastery": round(mastery, 2),
                    "count": row.total
                })
        
        # 4. 擅长点
        strong_points = [
            row.category for row in weak_rows
            if (row.correct / row.total) > 0.85
        ][:5]  # Top 5
        
        # 5. 推荐难度
        if correct_rate > 0.8:
            recommended_difficulty = 5  # 可以挑战更难
        elif correct_rate > 0.6:
            recommended_difficulty = 4  # 保持当前
        elif correct_rate > 0.4:
            recommended_difficulty = 3  # 适中
        else:
            recommended_difficulty = 2  # 回归基础
        
        # 6. 最近活动（最近10条记录）
        recent_query = select(LearningRecord).where(
            LearningRecord.user_id == user_id
        ).order_by(LearningRecord.created_at.desc()).limit(10)
        
        recent_result = await self.db.execute(recent_query)
        recent_records = recent_result.scalars().all()
        
        return {
            "total_questions": total_questions,
            "correct_rate": round(correct_rate, 2),
            "avg_time_per_question": round(avg_time, 1),
            "weak_points": weak_points[:5],  # Top 5 薄弱点
            "strong_points": strong_points,
            "recommended_difficulty": recommended_difficulty,
            "recent_activity": [
                {
                    "category": r.category,
                    "is_correct": r.is_correct,
                    "time": r.created_at.isoformat() if r.created_at else None
                }
                for r in recent_records
            ]
        }
    
    async def get_relevant_memories(
        self,
        user_id: str,
        query: str,
        limit: int = 10
    ) -> List[Dict[str, Any]]:
        """
        获取与查询相关的历史记忆
        
        策略：
        1. 同知识点的历史错题（权重最高）
        2. 类似问题的历史对话
        3. 近期的学习事件
        
        Args:
            user_id: 用户ID
            query: 查询文本
            limit: 返回数量上限
        
        Returns:
            相关记忆列表
        """
        from .models import LearningRecord, ChatMessage, ChatSession
        
        memories = []
        
        # Step 1: 识别查询中的知识点（简单关键词匹配）
        categories_in_query = self._extract_categories(query)
        
        # Step 2: 查询同知识点的错误记录
        if categories_in_query:
            error_query = select(LearningRecord).where(
                and_(
                    LearningRecord.user_id == user_id,
                    LearningRecord.category.in_(categories_in_query),
                    LearningRecord.is_correct == False
                )
            ).order_by(LearningRecord.created_at.desc()).limit(limit // 2)
            
            error_result = await self.db.execute(error_query)
            error_records = error_result.scalars().all()
            
            for record in error_records:
                memories.append({
                    "type": "historical_error",
                    "content": (
                        f"[{record.created_at.strftime('%Y-%m-%d')}] "
                        f"你在'{record.category}'这道题上出错过。"
                        f"\n题目: {record.question_content[:80]}..."
                        f"\n错误原因: {record.error_reason or '未记录'}"
                    ),
                    "category": record.category,
                    "relevance": 0.9,  # 高相关性
                    "timestamp": record.created_at.isoformat()
                })
        
        # Step 3: 查询最近的对话记录（包含相似关键词）
        keyword_match = f"%{query.split()[0] if query else ''}%"
        chat_query = select(ChatMessage).join(ChatSession).where(
            and_(
                ChatSession.user_id == user_id,
                ChatMessage.role == "assistant",
                ChatMessage.content.ilike(keyword_match)
            )
        ).order_by(ChatMessage.created_at.desc()).limit(limit // 2)
        
        chat_result = await self.db.execute(chat_query)
        chat_messages = chat_result.scalars().all()
        
        for msg in chat_messages:
            memories.append({
                "type": "conversation_memory",
                "content": msg.content[:200],
                "relevance": 0.7,
                "timestamp": msg.created_at.isoformat()
            })
        
        # Step 4: 按相关性和时间排序
        memories.sort(key=lambda m: (m["relevance"], m["timestamp"]), reverse=True)
        
        return memories[:limit]
    
    async def record_learning_event(self, event_data: Dict[str, Any]) -> bool:
        """
        记录一次学习事件
        
        Args:
            event_data: 事件数据字典
        
        Returns:
            是否成功
        """
        try:
            from .models import LearningRecord
            
            record = LearningRecord(**event_data)
            self.db.add(record)
            await self.db.commit()
            
            return True
        except Exception as e:
            await self.db.rollback()
            logger.error(f"记录学习事件失败: {e}")
            return False
    
    def _extract_categories(self, text: str) -> List[str]:
        """从文本中提取可能的知识点类别"""
        # 简单的关键词映射（实际项目中可使用 NLP 或 LLM 分类）
        category_keywords = {
            "积分": ["积分", "∫", "integral", "面积"],
            "导数": ["导数", "微分", "derivative", "斜率", "极限"],
            "极限": ["极限", "lim", "趋近", "无穷"],
            "级数": ["级数", "求和", "∑", "收敛", "发散"],
            "微分方程": ["微分方程", "dy/dx", "解方程"],
        }
        
        found_categories = []
        text_lower = text.lower()
        
        for category, keywords in category_keywords.items():
            if any(kw in text_lower for kw in keywords):
                found_categories.append(category)
        
        return found_categories
```

### 4.3 记忆检索引擎

```python
import asyncio
from typing import List, Tuple
import numpy as np
from dataclasses import dataclass


@dataclass
class RetrievalResult:
    """检索结果"""
    memory: MemoryItem
    score: float  # 相关性得分 0-1
    source: str  # "short_term" | "long_term"
    explanation: str  # 为什么匹配


class MemoryRetrievalEngine:
    """
    记忆检索引擎 - 混合检索策略
    
    策略：
    1. 短期记忆：快速关键词匹配（<5ms）
    2. 长期记忆：数据库查询（<50ms）
    3. 合并去重 + 重排序
    """
    
    def __init__(
        self,
        short_term_memory: ShortTermMemory,
        long_term_memory: LongTermMemory,
        weights: Dict[str, float] = None
    ):
        self.short_term = short_term_memory
        self.long_term = long_term
        
        # 检索源权重配置
        self.weights = weights or {
            "short_term": 0.4,  # 短期记忆权重
            "long_term": 0.6,  # 长期记忆权重
        }
    
    async def retrieve(
        self,
        query: str,
        user_id: str,
        top_k: int = 5,
        min_score: float = 0.3
    ) -> List[RetrievalResult]:
        """
        混合检索 - 从多个记忆源获取结果并合并
        
        Args:
            query: 查询文本
            user_id: 用户ID
            top_k: 返回数量
            min_score: 最低得分阈值
        
        Returns:
            排序后的检索结果列表
        """
        # 并行查询两个记忆源
        short_term_results, long_term_results = await asyncio.gather(
            self._retrieve_from_short_term(query, top_k * 2),
            self._retrieve_from_long_term(user_id, query, top_k * 2)
        )
        
        # 合并结果
        all_results = []
        
        for item, score in short_term_results:
            all_results.append(RetrievalResult(
                memory=item,
                score=score * self.weights["short_term"],
                source="short_term",
                explanation=f"来自当前会话的记忆 (相关性: {score:.2f})"
            ))
        
        for item_dict in long_term_results:
            # 将字典转换为 MemoryItem
            item = MemoryItem(
                id=item_dict.get("id", ""),
                content=item_dict.get("content", ""),
                memory_type=item_dict.get("type", "fact"),
                category=item_dict.get("category", ""),
                importance=item_dict.get("relevance", 0.5)
            )
            all_results.append(RetrievalResult(
                memory=item,
                score=item_dict.get("relevance", 0) * self.weights["long_term"],
                source="long_term",
                explanation=item_dict.get("content", "")[:100]
            ))
        
        # 去重（基于内容相似度）
        unique_results = self._deduplicate(all_results)
        
        # 过滤低分项
        filtered = [r for r in unique_results if r.score >= min_score]
        
        # 重排序（按最终得分）
        filtered.sort(key=lambda x: x.score, reverse=True)
        
        return filtered[:top_k]
    
    async def _retrieve_from_short_term(
        self, query: str, top_k: int
    ) -> List[Tuple[MemoryItem, float]]:
        """从短期记忆检索"""
        items = self.short_term.retrieve(query, top_k=top_k)
        return [(item, 0.9) for item in items]  # 短期记忆默认高分
    
    async def _retrieve_from_long_term(
        self, user_id: str, query: str, top_k: int
    ) -> List[Dict[str, Any]]:
        """从长期记忆检索"""
        return await self.long_term.get_relevant_memories(
            user_id=user_id,
            query=query,
            limit=top_k
        )
    
    def _deduplicate(
        self, results: List[RetrievalResult], threshold: float = 0.8
    ) -> List[RetrievalResult]:
        """
        去重 - 移除内容高度相似的条目
        
        策略：保留得分更高的那个
        """
        if not results:
            return results
        
        unique = [results[0]]
        
        for result in results[1:]:
            is_duplicate = False
            for existing in unique:
                similarity = self._text_similarity(
                    result.memory.content,
                    existing.memory.content
                )
                if similarity > threshold:
                    is_duplicate = True
                    break
            
            if not is_duplicate:
                unique.append(result)
        
        return unique
    
    def _text_similarity(self, text1: str, text2: str) -> float:
        """简单的文本相似度计算（Jaccard 系数）"""
        words1 = set(text1.lower().split())
        words2 = set(text2.lower().split())
        
        intersection = len(words1 & words2)
        union = len(words1 | words2)
        
        return intersection / union if union > 0 else 0
```

```python
from datetime import datetime, timedelta
from typing import Dict, List, Any, Optional
from collections import defaultdict
import statistics


class UserProfileAnalyzer:
    """
    用户画像分析器 - 多维度学习数据分析
    
    分析能力：
    1. 知识点掌握度计算
    2. 错误模式识别
    3. 学习习惯分析
    4. 个性化建议生成
    """
    
    def __init__(self, long_term_memory: LongTermMemory):
        self.memory = long_term_memory
    
    async def analyze(self, user_id: str) -> Dict[str, Any]:
        """
        执行完整的用户画像分析
        
        Returns:
            完整的用户画像字典
        """
        profile = await self.memory.get_user_profile(user_id)
        
        # 补充更多维度
        profile.update(await self._analyze_behavior_patterns(user_id))
        profile.update(await self._analyze_error_patterns(user_id))
        profile.update(await self._analyze_progress_trends(user_id))
        profile.update(await self._analyze_preferences(user_id))
        profile.update(self._generate_recommendations(profile))
        
        return profile
    
    async def _analyze_behavior_patterns(
        self, user_id: str
    ) -> Dict[str, Any]:
        """分析用户学习行为模式"""
        from .models import LearningRecord
        
        # 1. 学习频率分析（按天）
        daily_stats = await self._get_daily_statistics(user_id)
        
        # 2. 活跃时间段分析
        hourly_stats = await self._get_hourly_statistics(user_id)
        
        peak_hour = max(hourly_stats.items(), key=lambda x: x[1])[0] \
            if hourly_stats else 20
        
        # 3. 平均每日学习时长
        avg_daily_minutes = sum(daily_stats.values()) / max(len(daily_stats), 1)
        
        # 4. 连续学习天数
        streak = await self._calculate_streak(user_id)
        
        return {
            "behavior": {
                "avg_daily_minutes": round(avg_daily_minutes, 1),
                "peak_hour": f"{peak_hour:02d}:00",
                "active_hours": self._format_active_hours(hourly_stats),
                "learning_streak": streak,
                "total_days_analyzed": len(daily_stats)
            }
        }
    
    async def _analyze_error_patterns(
        self, user_id: str
    ) -> Dict[str, Any]:
        """分析错误模式和薄弱点"""
        from .models import LearningRecord
        
        # 1. 查询所有错误记录
        error_query = select(LearningRecord).where(
            and_(
                LearningRecord.user_id == user_id,
                LearningRecord.is_correct == False
            )
        )
        error_result = await self.memory.db.execute(error_query)
        errors = error_result.scalars().all()
        
        if not errors:
            return {"error_patterns": {}}
        
        # 2. 错误类型分布
        error_types = defaultdict(int)
        for e in errors:
            error_type = e.error_category or "unknown"
            error_types[error_type] += 1
        
        total_errors = len(errors)
        error_type_dist = {
            k: round(v / total_errors * 100, 1)
            for k, v in sorted(error_types.items(), key=lambda x: -x[1])
        }
        
        # 3. 常见错误原因（Top 5）
        error_reasons = defaultdict(int)
        for e in errors:
            if e.error_reason:
                error_reasons[e.error_reason[:50]] += 1
        
        common_errors = sorted(
            error_reasons.items(),
            key=lambda x: -x[1]
        )[:5]
        
        return {
            "error_patterns": {
                "total_errors": total_errors,
                "error_rate": round(total_errors / max(total_errors + sum(1 for _ in errors if _.is_correct), 1), 2),
                "error_type_distribution": error_type_dist,
                "common_error_reasons": [
                    {"reason": r, "count": c} for r, c in common_errors
                ]
            }
        }
    
    async def _analyze_progress_trends(
        self, user_id: str
    ) -> Dict[str, Any]:
        """分析进步趋势"""
        from .models import LearningRecord
        from sqlalchemy import desc
        
        # 1. 获取最近 30 天的记录
        thirty_days_ago = datetime.now() - timedelta(days=30)
        
        trend_query = select(LearningRecord).where(
            and_(
                LearningRecord.user_id == user_id,
                LearningRecord.created_at >= thirty_days_ago,
                LearningRecord.is_correct.isnot(None)
            )
        ).order_by(desc(LearningRecord.created_at))
        
        trend_result = await self.memory.db.execute(trend_query)
        records = trend_result.scalars().all()
        
        if len(records) < 10:
            return {"progress_trends": {"insufficient_data": True}}
        
        # 2. 计算滑动窗口正确率（7天窗口）
        window_size = 7
        correct_rates = []
        
        for i in range(0, len(records), window_size):
            window = records[i:i+window_size]
            if len(window) > 0:
                correct = sum(1 for r in window if r.is_correct)
                rate = correct / len(window)
                correct_rates.append(rate)
        
        if len(correct_rates) >= 2:
            # 计算趋势（线性回归斜率）
            trend_slope = self._linear_regression_slope(correct_rates)
            trend_direction = "↑" if trend_slope > 0.01 else ("↓" if trend_slope < -0.01 else "→")
            trend_percentage = abs(trend_slope) * 100
        else:
            trend_direction = "→"
            trend_percentage = 0
        
        # 3. 计算本周 vs 上周对比
        one_week_ago = datetime.now() - timedelta(days=7)
        this_week = [r for r in records if r.created_at >= one_week_ago]
        last_week = [r for r in records if r.created_at < one_week_ago >= (one_week_ago - timedelta(days=7))]
        
        this_week_rate = (
            sum(1 for r in this_week if r.is_correct) / len(this_week)
        ) if this_week else 0
        
        last_week_rate = (
            sum(1 for r in last_week if r.is_correct) / len(last_week)
        ) if last_week else 0
        
        week_over_week_change = this_week_rate - last_week_rate
        
        return {
            "progress_trends": {
                "trend_direction": trend_direction,
                "trend_percentage": round(trend_percentage, 1),
                "this_week_correct_rate": round(this_week_rate, 2),
                "last_week_correct_rate": round(last_week_rate, 2),
                "week_over_week_change": round(week_over_week_change * 100, 1),
                "data_points": len(records)
            }
        }
    
    async def _analyze_preferences(
        self, user_id: str
    ) -> Dict[str, Any]:
        """分析用户偏好"""
        from .models import LearningRecord
        
        # 1. 题型偏好
        type_query = select(
            LearningRecord.question_type,
            func.count().label("count")
        ).where(
            LearningRecord.user_id == user_id
        ).group_by(LearningRecord.question_type)
        
        type_result = await self.memory.db.execute(type_query)
        type_rows = type_result.all()
        
        total = sum(row.count for row in type_rows)
        type_preference = {
            row.question_type: round(row.count / total * 100, 1)
            for row in type_rows
        } if total > 0 else {}
        
        # 2. 难度偏好
        diff_query = select(
            LearningRecord.difficulty,
            func.count().label("count"),
            func.avg(
                func.cast(LearningRecord.is_correct, Integer)
            ).label("accuracy")
        ).where(
            LearningRecord.user_id == user_id
        ).group_by(LearningRecord.difficulty)
        
        diff_result = await self.memory.db.execute(diff_query)
        diff_rows = diff_result.all()
        
        difficulty_preference = {}
        best_accuracy_diff = 1
        best_accuracy = 0
        
        for row in diff_rows:
            accuracy = row.accuracy or 0
            difficulty_preference[row.difficulty] = {
                "count": row.count,
                "accuracy": round(accuracy, 2)
            }
            
            if accuracy > best_accuracy and row.count >= 5:
                best_accuracy = accuracy
                best_accuracy_diff = row.difficulty
        
        return {
            "preferences": {
                "question_type": type_preference,
                "difficulty": difficulty_preference,
                "preferred_difficulty": best_accuracy_diff,
                "preferred_question_type": max(
                    type_preference.items(), key=lambda x: x[1]
                )[0] if type_preference else "unknown"
            }
        }
    
    def _generate_recommendations(
        self, base_profile: Dict[str, Any]
    ) -> Dict[str, Any]:
        """基于画像生成个性化建议"""
        recommendations = []
        
        # 1. 薄弱点改进建议
        weak_points = base_profile.get("weak_points", [])
        if weak_points:
            weakest = weak_points[0]["category"]
            mastery = weak_points[0].get("mastery", 0)
            recommendations.append({
                "type": "improvement",
                "priority": "high",
                "message": f"重点加强「{weakest}」(当前掌握度: {mastery:.0%})",
                "action": "practice",
                "target_category": weakest
            })
        
        # 2. 难度调整建议
        current_rec = base_profile.get("recommended_difficulty", 3)
        correct_rate = base_profile.get("correct_rate", 0.5)
        
        if correct_rate > 0.85 and current_rec < 5:
            recommendations.append({
                "type": "challenge",
                "priority": "medium",
                "message": f"你的正确率已达到 {correct_rate:.0%}，可以尝试更高难度的题目",
                "action": "increase_difficulty",
                "target_difficulty": current_rec + 1
            })
        elif correct_rate < 0.5 and current_rec > 1:
            recommendations.append({
                "type": "review",
                "priority": "high",
                "message": "建议先巩固基础，降低练习难度",
                "action": "decrease_difficulty",
                "target_difficulty": max(1, current_rec - 1)
            })
        
        # 3. 学习习惯建议
        behavior = base_profile.get("behavior", {})
        avg_daily = behavior.get("avg_daily_minutes", 0)
        
        if avg_daily < 15:
            recommendations.append({
                "type": "habit",
                "priority": "low",
                "message": "每天至少练习 15 分钟才能保持学习效果",
                "action": "increase_practice_time",
                "target_minutes": 30
            })
        
        return {"recommendations": recommendations}
    
    # ==================== 辅助方法 ====================
    
    async def _get_daily_statistics(
        self, user_id: str
    ) -> Dict[str, int]:
        """获取每日学习统计数据"""
        from .models import LearningRecord
        from sqlalchemy import func, date
        
        query = select(
            func.date(LearningRecord.created_at).label("day"),
            func.count().label("count")
        ).where(
            LearningRecord.user_id == user_id
        ).group_by(date(LearningRecord.created_at)).order_by(
            date(LearningRecord.created_at).desc()
        ).limit(30)
        
        result = await self.memory.db.execute(query)
        rows = result.all()
        return {str(row.day): row.count for row in rows}
    
    async def _get_hourly_statistics(
        self, user_id: str
    ) -> Dict[int, int]:
        """获取每小时活跃统计"""
        from .models import LearningRecord
        from sqlalchemy import extract
        
        query = select(
            extract("hour", LearningRecord.created_at).label("hour"),
            func.count().label("count")
        ).where(
            LearningRecord.user_id == user_id
        ).group_by(extract("hour", LearningRecord.created_at))
        
        result = await self.memory.db.execute(query)
        rows = result.all()
        return {int(row.hour): row.count for row in rows}
    
    async def _calculate_streak(self, user_id: str) -> int:
        """计算连续学习天数"""
        daily_stats = await self._get_daily_statistics(user_id)
        dates = sorted(datetime.strptime(d, "%Y-%m-%d") for d in daily_stats.keys())
        
        if not dates:
            return 0
        
        streak = 1
        today = datetime.now().date()
        
        # 从今天往前检查
        check_date = today - timedelta(days=1)
        while check_date in [d.date() for d in dates]:
            streak += 1
            check_date -= timedelta(days=1)
        
        return streak
    
    def _format_active_hours(self, hourly_stats: Dict[int, int]) -> str:
        """格式化活跃时间段"""
        if not hourly_stats:
            return "暂无数据"
        
        active_hours = sorted(hourly_stats.items(), key=lambda x: -x[1])[:3]
        ranges = []
        
        for hour, count in active_hours:
            ranges.append(f"{hour:02d}:00-{(hour+1)%24:02d}:00 ({count}次)")
        
        return ", ".join(ranges)
    
    def _linear_regression_slope(self, y_values: List[float]) -> float:
        """计算线性回归斜率"""
        n = len(y_values)
        if n < 2:
            return 0
        
        x_mean = (n - 1) / 2
        y_mean = statistics.mean(y_values)
        
        numerator = sum(
            (i - x_mean) * (y - y_mean)
            for i, y in enumerate(y_values)
        )
        denominator = sum((i - x_mean) ** 2 for i in range(n))
        
        return numerator / denominator if denominator != 0 else 0
```

```python
        func.sum(case((LearningRecord.is_correct == True,), 1)).label("correct"),
        func.avg(LearningRecord.time_spent).label("avg_time"),
        func.count(func.distinct(LearningRecord.category)).label("categories_count")
    ).where(LearningRecord.user_id == user_id)
    
    result = await db.execute(stmt)
    row = result.one()

        "total": row.total or 0,
        "correct": row.correct or 0,
```

### 7.2 缓存策略

#### 7.2.1 多级缓存架构

```
请求 → L1 Cache (进程内) → L2 Cache (Redis) → Database
         ↗ 未命中          ↗ 未命中         ↗ 查询
         ↓                ↓                ↓
       返回结果         返回结果         写入L2→L1→返回
```

#### 7.2.2 Redis 缓存实现

```python
import redis.asyncio as aioredis
import json
import pickle
from typing import Optional, Any
from functools import wraps


class CacheManager:
    """
    多级缓存管理器
    
    层级说明：
    - L1: 内存字典（进程内，无网络开销，毫秒级响应）
    - L2: Redis（跨进程共享，适合热点数据）
    """
    
    def __init__(self, redis_url: str = "redis://localhost:6379"):
        self.redis: Optional[aioredis.Redis] = None
        self.l1_cache: Dict[str, Any] = {}  # 内存缓存
        self.l1_max_size = 1000  # L1 最大容量
        self.l1_hits = 0
        self.l2_hits = 0
        self.misses = 0
    
    async def initialize(self):
        """初始化 Redis 连接"""
        self.redis = aioredis.from_url(redis_url, decode_responses=True)
        try:
            await self.redis.ping()
            logger.info("Redis 连接成功")
        except Exception as e:
            logger.warning(f"Redis 连接失败，将仅使用 L1 缓存: {e}")
            self.redis = None
    
    async def get(self, key: str) -> Optional[Any]:
        """
        获取缓存值（L1 → L2 逐级查找）
        """
        # L1 查找
        if key in self.l1_cache:
            self.l1_hits += 1
            return self.l1_cache[key]
        
        # L2 查找
        if self.redis:
            cached = await self.redis.get(f"cache:{key}")
            if cached:
                self.l2_hits += 1
                value = pickle.loads(cached.encode()) if isinstance(cached, str) else cached
                # 回填 L1
                self._set_l1(key, value)
                return value
        
        self.misses += 1
        return None
    
    async def set(
        self, key: str, value: Any, ttl: int = 3600,
        use_l1: bool = True, use_l2: bool = True
    ):
        """
        设置缓存值
        
        Args:
            key: 缓存键
            value: 缓存值
            ttl: 生存时间（秒）
            use_l1: 是否写入 L1
            use_l2: 是否写入 L2
        """
        if use_l1:
            self._set_l1(key, value)
        
        if use_l2 and self.redis:
            serialized = pickle.dumps(value)
            await self.redis.setex(f"cache:{key}", ttl, serialized)
    
    async def delete(self, key: str):
        """删除缓存"""
        self.l1_cache.pop(key, None)
        if self.redis:
            await self.redis.delete(f"cache:{key}")
    
    async def invalidate_pattern(self, pattern: str):
        """批量失效（如 user:*:profile）"""
        keys_to_remove = [k for k in self.l1_cache if pattern in k]
        for k in keys_to_remove:
            del self.l1_cache[k]
        
        if self.redis:
            cursor = 0
            while True:
                cursor, keys = await self.redis.scan(cursor, match=f"cache:{pattern}", count=100)
                if keys:
                    await self.redis.delete(*keys)
                if cursor == 0:
                    break
    
    def _set_l1(self, key: str, value: Any):
        """写入 L1 缓存（带容量控制）"""
        if len(self.l1_cache) >= self.l1_max_size:
            # 淘汰最少使用的项
            evict_key = next(iter(self.l1_cache))
            del self.l1_cache[evict_key]
        
        self.l1_cache[key] = value
    
    @property
    def stats(self) -> Dict[str, Any]:
        total = self.l1_hits + self.l2_hits + self.misses
        return {
            "l1_size": len(self.l1_cache),
            "l1_max_size": self.l1_max_size,
            "hits": {
                "l1": self.l1_hits,
                "l2": self.l2_hits,
                "total": self.l1_hits + self.l2_hits,
            },
            "misses": self.misses,
            "hit_rate": (self.l1_hits + self.l2_hits) / max(total, 1),
            "l1_hit_rate": self.l1_hits / max(total, 1),
        }


# 使用装饰器简化缓存
def cache_result(ttl: int = 3600, prefix: str = ""):
    """
    缓存装饰器 - 自动缓存函数结果
    
    用法:
    @cache_result(ttl=1800, prefix="user:")
    async def get_user_profile(user_id: str):
        ...  # 复杂查询
    """
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            cache_manager = get_cache_manager()  # 获取全局实例
            
            # 生成缓存键
            cache_key = f"{prefix}{func.__name__}:{str(args)}:{str(kwargs)}"
            
            # 尝试获取缓存
            cached = await cache_manager.get(cache_key)
            if cached is not None:
                return cached
            
            # 执行原函数
            result = await func(*args, **kwargs)
            
            # 写入缓存
            await cache_manager.set(cache_key, result, ttl=ttl)
            
            return result
        return wrapper
    return decorator
```

```python
from cryptography.fernet import Fernet
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.kdf.pbkdf2 import PBKDF2HMAC
import os
import base64


class DataEncryption:
    """
    数据加密工具类
    
    加密层次：
    1. 传输加密: TLS 1.3（HTTPS）
    2. 应用加密: AES-256-GCM（敏感字段）
    3. 存储加密: 透明数据加密（TDE，可选）
    """
    
    def __init__(self, encryption_key: bytes = None):
        if encryption_key is None:
            # 从环境变量读取或生成
            key_str = os.environ.get("ENCRYPTION_KEY")
            if key_str:
                encryption_key = base64.urlsafe_b64decode(key_str)
            else:
                # 生成新密钥（首次运行时）
                encryption_key = Fernet.generate_key()
                print(f"⚠️  请保存此加密密钥: {encryption_key.decode()}")
        
        self.fernet = Fernet(encryption_key)
    
    def encrypt_field(self, plaintext: str) -> str:
        """加密单个字段"""
        if not plaintext:
            return ""
        encrypted = self.fernet.encrypt(plaintext.encode())
        return base64.urlsafe_b64encode(encrypted).decode()
    
    def decrypt_field(self, ciphertext: str) -> str:
        """解密单个字段"""
        if not ciphertext:
            return ""
        encrypted = base64.urlsafe_b64decode(ciphertext.encode())
        decrypted = self.fernet.decrypt(encrypted)
        return decrypted.decode()
    
    def encrypt_sensitive_user_data(self, user_data: Dict) -> Dict:
        """加密用户敏感数据"""
        sensitive_fields = [
            "email", "phone", "real_name",
            "id_card", "address", "emergency_contact"
        ]
        
        encrypted_data = user_data.copy()
        for field in sensitive_fields:
            if field in encrypted_data and encrypted_data[field]:
                encrypted_data[field] = self.encrypt_field(str(encrypted_data[field]))
                encrypted_data[f"{field}_encrypted"] = True
        
        return encrypted_data
    
    def hash_password(self, password: str) -> str:
        """密码哈希（bcrypt 风格，使用 PBKDF2）"""
        salt = os.urandom(16)
        kdf = PBKDF2HMAC(
            algorithm=hashes.SHA256(),
            length=32,
            salt=salt,
            iterations=100000,  # 高迭代次数防止暴力破解
        )
        key = kdf.derive(password.encode())
        return base64.urlsafe_b64encode(salt + key).decode()
    
    def verify_password(self, hashed_password: str, password: str) -> bool:
        """密码验证"""
        try:
            decoded = base64.urlsafe_b64decode(hashed_password)
            salt = decoded[:16]
            stored_key = decoded[16:]
            
            kdf = PBKDF2HMAC(
                algorithm=hashes.SHA256(),
                length=32,
                salt=salt,
                iterations=100000,
            )
            new_key = kdf.derive(password.encode())
            
            return stored_key == new_key
        except Exception:
            return False
```

```python
    权限装饰器

    @require_permission(Permission.READ_ALL_DATA)
    async def get_all_users(request: Request):
        ...
    """

        @wraps(func)
        async def wrapper(*args, **kwargs):
            # 从请求中提取用户信息
            request = kwargs.get("request") or args[0] if args else None
            if not request:

                    status_code=403,
                    detail=f"权限不足: 需要 {permission.value}"
                )
            
            return await func(*args, **kwargs)
        return wrapper
    return decorator
```

### 10.3 监控与健康检查

```python
from fastapi import APIRouter
from datetime import datetime
import psutil  # 系统监控库

router = APIRouter(prefix="/health", tags=["health"])


@router.get("")
async def health_check():
    """健康检查端点（用于负载均衡器和监控系统）"""
    return {
        "status": "healthy",
        "service": "math-ai-agent-data",
        "timestamp": datetime.now().isoformat(),
        "version": "1.0.0"
    }


@router.get("/detailed")
async def detailed_health():
    """详细健康检查（包含各子系统的状态）"""
    checks = {
        "database": await _check_database(),
        "redis": await _check_redis(),
        "disk_space": _check_disk_space(),
        "memory_usage": _check_memory_usage(),
        "cpu_load": _check_cpu_load(),
    }
    
    overall_status = "healthy" if all(
        c["status"] == "healthy" for c in checks.values()
    ) else "degraded"
    
    return {
        "status": overall_status,
        "checks": checks,
        "timestamp": datetime.now().isoformat()
    }


async def _check_database() -> Dict:
    """检查数据库连接"""
    try:
        from app.data.database import engine
        
        async with engine.connect() as conn:
            await conn.execute(text("SELECT 1"))
        
        return {"status": "healthy", "latency_ms": "<10"}
    except Exception as e:
        return {"status": "unhealthy", "error": str(e)}


async def _check_redis() -> Dict:
    """检查 Redis 连接"""
    try:
        from app.services.cache import cache_manager
        
        if cache_manager and cache_manager.redis:
            await cache_manager.redis.ping()
            return {"status": "healthy", "latency_ms": "<5"}
        return {"status": "skipped", "message": "Redis 未配置"}
    except Exception as e:
        return {"status": "unhealthy", "error": str(e)}


def _check_disk_space() -> Dict:
    """检查磁盘空间"""
    disk = psutil.disk_usage('/')
    percent_used = disk.percent
    
    if percent_used > 90:
        status = "warning"
    elif percent_used > 95:
        status = "critical"
    else:
        status = "healthy"
    
    return {
        "status": status,
        "used_percent": percent_used,
        "free_gb": round(disk.free / (1024**3), 2),
        "total_gb": round(disk.total / (1024**3), 2)
    }


def _check_memory_usage() -> Dict:
    """检查内存使用"""
    mem = psutil.virtual_memory()
    percent_used = mem.percent
    
    return {
        "status": "healthy" if percent_used < 90 else "warning",
        "used_percent": percent_used,
        "available_mb": round(mem.available / (1024**2), 2),
        "total_gb": round(mem.total / (1024**3), 2)
    }


def _check_cpu_load() -> Dict:
    """检查 CPU 负载"""
    load_avg = psutil.getloadavg()
    
    return {
        "status": "healthy" if load_avg[0] < cpu_count() * 2 else "warning",
        "load_1min": round(load_avg[0], 2),
        "load_5min": round(load_avg[1], 2),
        "load_15min": round(load_avg[2], 2),
        "cpu_count": cpu_count()
    }


def cpu_count() -> int:
    return psutil.cpu_count(logical=False)
```

### B. 安全检查清单

- [ ] 所有敏感字段使用 AES-256-GCM 加密存储
- [ ] 密码使用 PBKDF2-HMAC-SHA256 哈希（迭代 100000 次）
- [ ] JWT Token 有效期 ≤ 24h，Refresh Token ≤ 7天
- [ ] API 限流：普通用户 30/min，管理员 100/min
- [ ] SQL 注入防护：全部使用参数化查询
- [ ] XSS 防护：输出转义 + CSP 头
- [ ] CSRF 防护：POST/PUT/DELETE 使用 SameSite Cookie
- [ ] 审计日志：记录所有数据修改和敏感操作
- [ ] GDPR 合规：支持用户数据导出和删除
- [ ] 定期备份：每日全量 + 每小时增量
- [ ] 访问控制：基于角色的权限检查（RBAC）
- [ ] 数据脱敏：日志和错误信息中不包含明文敏感数据

### C. 故障排查指南

| 问题现象 | 可能原因 | 排查步骤 |
|---------|---------|---------|
| 数据库连接超时 | 连接池耗尽 | 检查 pool_size、慢查询日志 |
| 缓存命中率低 | TTL 设置过短 | 调整缓存策略、增加预热 |
| 查询响应慢 | 缺少索引 | 使用 EXPLAIN ANALYZE 分析 |
| 内存占用过高 | 连接泄漏 | 检查 session 是否正确关闭 |
| 数据不一致 | 并发冲突 | 检查事务隔离级别、乐观锁 |
