# 前端重构 Phase 1：已知失败与技术债

| 问题 | 影响 | 下一步 | 阶段 |
|---|---|---|---|
| 受限 shell 阻止 `npm.ps1` | README 中的原始命令无法直接执行 | 使用 `npm.cmd`，并在真实环境复验 | Phase 1 验证 |
| bundled Python 没有 `pytest` | bundled 运行时无法执行后端测试 | 使用项目虚拟环境或 CI Python | Phase 1 验证 |
| Compose 要求三个密钥 | 环境变量不完整时无法校验配置 | 只通过环境变量提供密钥 | Phase 1 验证 |
| 受限 shell 中前端构建出现配置解析权限错误 | 构建证据不完整 | 在受限环境外复跑，不要仅为此修改 Vite 配置 | Phase 1 验证 |
| Compose 使用 Qdrant `latest` | 可复现性较弱 | 在基础设施改动中固定经过批准的镜像版本 | Phase 2 候选项 |
| 本地对话状态与后端聊天模型并存 | 刷新和账号语义可能不一致 | 定义权威的 `ChatSession/ChatMessage` 契约 | Phase 3 候选项 |
| 多处 HTML/Markdown 渲染调用点 | 存在 XSS 和视觉漂移风险 | 统一渲染器，并测试 KaTeX/SSE 内容 | Phase 2 候选项 |
| 旧主题变量与新设计令牌并存 | 新 UI 可能再次产生第二套视觉语言 | 在现有外壳后增加语义令牌并逐步迁移 | Phase 2 |
| 侧栏上下文菜单曾使用 emoji 字符 | 不符合冻结的图标规则 | 在外壳迁移中替换 | Phase 2 |

以上问题均不授权在 Phase 1 进行大范围清理。后续处理必须保留现有未提交改动，并附带针对性的回归检查。
