# 前端重构 Phase 1：设计与范围冻结

设计唯一依据为 `docs/UI_UX_MASTER_PLAN.md`。

## 已冻结的产品方向

- 产品方向：Editorial Intelligence + Cognitive Canvas，即“编辑式智能 + 认知画布”。
- 浅色表面用于阅读和学习；深色画布只用于知识关系展示。
- 一级导航为“今日”（`/`）、“提问”（`/chat`）、“课程”（`/knowledge`）和“错题复盘”（`/error-book`）。
- 保持现有 URL 不变，包括 `/knowledge/points/:pointId/learn`。
- 学习路径、资料库和完整知识图谱入口不能做成没有真实功能的空页面。

Phase 2 不允许在新组件中继续新增页面级硬编码十六进制颜色。

## 已冻结的交互规则

- 每个页面最多一个主 CTA。
- 只有图标的控件必须有可访问名称，点击区域至少 44px。
- 异步操作必须显示加载、禁用、成功/失败和恢复状态。
- 错误、掌握度和锁定状态不能只通过颜色表达。
- 新增或迁移的 UI 不得使用结构性 emoji 图标。
- 保留键盘焦点，并支持 `prefers-reduced-motion`。
- 刷新页面时不得静默丢失未保存的学习或聊天状态。

## Phase 1 明确不做的内容

- 重写页面布局。
- 修改后端业务逻辑或数据模型。
- 新增课程、题目批次、Agent/RAG/prompt/数据库优化。
- 引入新的组件库或 CSS 框架。
- 替换 Three.js 或实现默认二维图谱。
- 将未完成的知识功能宣称为稳定功能。
- 清理与本次重构边界无关的历史技术债。

## Phase 2 开始条件

只有当基线命令、五条冒烟路径、职责矩阵、路由表、设计令牌和已知阻塞项都已经在 Phase 1 报告中建立链接并指定负责人后，才能开始 Phase 2。
