## 三、重构方案制定

### 3.1 重构原则

```
📌 重构指导原则:
1. 渐进式重构: 不破坏现有功能，逐步优化
2. 测试驱动: 先写测试，再重构代码
3. 优先级排序: P0安全 → P1架构 → P2体验
4. 三人并行: 明确接口契约，减少互相等待
5. 学习导向: 每次重构都提升团队能力
```

### 3.2 重构阶段划分

#### Phase 1: 紧急修复（第1-2周）🔴

**目标**: 堵住安全漏洞，稳定基础架构

| 任务 | 工作量 | 负责人 | 验收标准 |
|------|--------|--------|---------|
| CORS配置收紧 | 0.5天 | AI专业 | 限制为localhost |
| API密钥加密存储 | 1天 | AI专业 | 环境变量+加密 |
| JWT认证系统 | 3天 | AI专业 | 登录/注册/中间件 |
| 输入过滤(XSS/注入) | 1.5天 | AI专业 | 所有API端点防护 |
| SQLite迁移 | 2天 | 统计专业 | 错题本数据迁移 |
| 单元测试框架搭建 | 1天 | 统计专业 | pytest框架+首个测试 |

**总工作量**: 9人天
**并行策略**: AI专业做安全，统计专业做数据库和测试

#### Phase 2: 架构重构（第3-5周）🟠

**目标**: 代码模块化，支持团队协作

| 任务 | 工作量 | 负责人 | 验收标准 |
|------|--------|--------|---------|
| main.py拆分(路由/服务) | 2天 | AI专业 | 模块职责清晰 |
| 工具注册中心实现 | 2天 | AI专业 | ToolRegistry可用 |
| 任务规划器实现 | 3天 | AI专业 | 支持2-3步分解 |
| React前端初始化 | 3天 | 商科专业 | 项目脚手架+基础组件 |
| 错题卡片组件开发 | 3天 | 商科专业 | 展开/收起功能 |
| 详情模态框开发 | 3天 | 商科专业 | 完整信息展示 |
| 记忆管理器实现 | 3天 | 统计专业 | 学习记录存储 |
| 学习分析模块 | 3天 | 统计专业 | 基础统计报表 |

**总工作量**: 22人天
**并行策略**: 后端(AI+统计) 和 前端(商科) 独立开发

#### Phase 3: 体验升级（第6-8周）🟡

**目标**: 用户体验显著提升，Agent能力增强

### 6.3 关键知识点讲解

#### 1. JWT认证原理（AI专业必学）

```python
# JWT三部分组成:
# Header(头部).Payload(载荷).Signature(签名)

# 签发Token（登录成功时）
import jwt
from datetime import datetime, timedelta

def create_token(user_id: str, secret: str):
    payload = {
        "user_id": user_id,
        "exp": datetime.utcnow() + timedelta(hours=24),  # 过期时间
        "iat": datetime.utcnow()  # 签发时间
    }
    token = jwt.encode(payload, secret, algorithm="HS256")
    return token

# 验证Token（每次请求时）
def verify_token(token: str, secret: str):
    try:
        payload = jwt.decode(token, secret, algorithms=["HS256"])
        return payload["user_id"]
    except jwt.ExpiredSignatureError:
        return None  # Token过期
    except jwt.InvalidTokenError:
        return None  # Token无效

# FastAPI中间件集成
from fastapi import Request, HTTPException

@app.middleware("http")
async def auth_middleware(request: Request, call_next):
    # 跳过认证的路由
    if request.url.path in ["/api/auth/login", "/api/auth/register"]:
        return await call_next(request)
    
    # 验证Token
    token = request.headers.get("Authorization", "").replace("Bearer ", "")
    user_id = verify_token(token, SECRET_KEY)
    
    if not user_id:
        raise HTTPException(status_code=401, detail="未认证")
    
    return await call_next(request)
```
