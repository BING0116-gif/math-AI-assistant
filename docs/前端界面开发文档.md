## 2 登录界面 LoginView

### 2.1 界面功能描述

LoginView 是系统的身份认证入口页面，提供用户名+密码登录、JWT 令牌签发、登录状态持久化、注册跳转以及密码可见性切换等功能。支持亮色/暗色双主题渲染。

**核心功能清单：**

| 功能 | 说明 |
|------|------|
| 账号密码登录 | 调用 `/api/auth/login` 获取 Access Token + Refresh Token |
| Token 存储 | 成功后写入 `localStorage('auth_token')` / `localStorage('refresh_token')` |
| 表单实时校验 | 用户名格式校验（实时）、密码非空校验（失焦） |
| 密码可见切换 | 点击眼睛图标切换密码明文/密文 |
| 登录错误反馈 | 401 错误显示"用户名或密码错误" Toast |
| 跳转注册页 | "还没有账号？立即注册" 文字链接 → `/register` |
| 登录成功跳转 | 自动跳转至 `/`（HomeView） |
| 键盘快捷操作 | 回车键提交表单 |
| 主题自适应 | 使用 `--bg-main` `--text-primary` 等 CSS 变量 |

### 2.2 核心交互流程

```
┌─────────────────────────────────────────────────────────────┐
│                     LoginView 交互流程                      │
│                                                             │
│  用户打开 /login                                            │
│  │                                                          │
│  ├─ 检查 localStorage.auth_token 是否有效                   │
│  │   ├─ 有效 → 自动跳转至 /                                │
│  │   └─ 无效/不存在 → 显示登录表单                          │
│  │                                                          │
│  ├─ 用户输入 username + password                            │
│  │   ├─ 实时校验 username 格式 (3-32位)                     │
│  │   └─ password 密码可见切换 (点击 👁 图标)                 │
│  │                                                          │
│  ├─ 点击"登录"按钮 或 按下 Enter                            │
│  │   ├─ 前端校验通过 → 按钮进入 loading 态                  │
│  │   └─ POST /api/auth/login                                │
│  │       ├─ 200: 存储 token → 跳转 /                       │
│  │       ├─ 401: Toast "用户名或密码错误" → 清空密码        │
│  │       └─ 其他: Toast "网络异常，请稍后再试"              │
│  │                                                          │
│  └─ 点击"立即注册" → router.push('/register')              │
└─────────────────────────────────────────────────────────────┘
```

### 2.6 数据接口需求

**登录接口：**

| 项目 | 详情 |
|------|------|
| **端点** | `POST /api/auth/login` |
| **Content-Type** | `application/json` |
| **请求体** | `{ "username": string, "password": string }` |
| **成功响应 (200)** | `{ "status": "success", "data": { "user_id": "...", "username": "...", "access_token": "...", "refresh_token": "...", "token_type": "bearer", "expires_in": 86400 } }` |
| **失败响应 (401)** | `{ "detail": "用户名或密码错误" }` |
| **失败响应 (400)** | `{ "detail": "用户名不能为空" / "用户名格式不合法" }` |

**Store 操作：**

```js
// authStore 操作
authStore.login(username, password)
  → 成功后 store 更新 userInfo + isAuthenticated
  → localStorage 存储 access_token / refresh_token
  → Axios 拦截器自动在请求头注入 Authorization

authStore.logout()
  → 清除 localStorage token
  → router.push('/login')
```

## 3 组卷界面 ExamCreatorView

### 3.1 界面功能描述

ExamCreatorView 是智能组卷功能的核心界面，允许用户通过自然语言描述或配置面板定义试卷需求（知识点范围、难度分布、题型比例、题目数量），由 AI 自动从题库（`questions` 表）中筛选匹配题目，生成结构化试卷。支持试卷预览、题目替换、一键发布与历史试卷管理。

**数据来源：** 后端 `app/data/models.py` 中的 `ExamPaper` 和 `ExamSubmission` 表已定义完整数据模型；`Question` 表包含 `category` / `difficulty` / `question_type` / `complexity_score` 等筛选维度。

**核心功能清单：**

| 功能 | 说明 |
|------|------|
| 自然语言组卷 | 输入 "生成一份微积分期中模拟卷，含10道选择题+5道计算题" |
| 配置式组卷 | 可视化表单：分类/难度/题型/数量/总分 |
| 智能选题 | AI 根据配置从题库筛选 + 自动平衡难度分布 |
| 试卷预览 | 生成的试卷以列表+卡片形式预览，含分值、题型标签 |
| 题目替换 | 对不满意的题目点击"换一题"重新抽取 |
| 试卷保存/发布 | 保存为草稿或生成分享链接 |
| 历史试卷管理 | 列表展示已生成的试卷，支持重新打开与删除 |
| 打印导出 | 导出为 PDF / 打印友好格式 |

## 4 聊天界面 ChatView

### 4.1 界面功能描述

ChatView 是系统的核心功能页面，提供用户与 AI 数学助手的智能对话交互。支持 SSE 流式响应（打字机效果）、多模态输入（文本 + 图片粘贴）、Markdown 渲染、KaTeX 数学公式渲染、自动错题收录提示以及多会话管理。

**核心功能清单：**

## 6 知识图谱界面 SkillGraphView

### 6.1 界面功能描述

SkillGraphView 是数学技能知识图谱的可视化页面，以 DAG（有向无环图）力导向布局展示各数学知识点之间的前置依赖关系，并叠加用户的个人技能掌握度数据。支持节点交互（点击查看技能详情）、图例筛选、搜索定位、推荐学习路径高亮等功能。

## 7 学情分析界面 LearningDashboardView

### 7.1 界面功能描述

LearningDashboardView 是学生学习数据的可视化仪表盘页面，通过图表与统计卡片全面展示个人学习状况。数据来源为用户画像 API（`/api/profile/{user_id}`）和记忆系统 API（`/api/memory/events`），涵盖正确率趋势、知识点雷达图、薄弱环节分析、学习时段分布、错题分布、近期活动时间线以及 AI 生成的个性化学习建议。

**核心功能清单：**

| 功能 | 说明 |
|------|------|
| 概览统计卡片 | 总题数 / 正确率 / 学习时长 / 连续学习天数 / 学习等级 |
| 正确率趋势图 | 折线图，日/周/月维度切换 |
| 知识点雷达图 | 各知识点掌握度雷达分布 |
| 薄弱环节列表 | 弱项知识点进度条列表 + 练习入口 |
| 学习时段热力图 | 每周各时段学习活跃度柱状图 |
| 错题分布饼图 | 错题按分类占比 |
| 近期活动时间线 | 最近 N 条学习事件 |
| AI 学习建议卡片 | 基于 profile.recommendations 渲染 |
| 日期范围选择 | 本周/本月/本学期/自定义 |

### 7.2 核心交互流程

```
进入 /dashboard
    │
    ▼
onMounted:
    ├─ GET /api/profile/{user_id}?include_recommendations=true
    │   → dashboardStore.setProfile(data)
    │
    ├─ GET /api/memory/events (近30天)

用户操作:
    ├─ 日期选择: [本周] [本月] [本学期] [自定义]

    ├─ 薄弱环节列表 → 点击卡片
    │   ├─ "去练习" → ChatView (携带知识点)
    │   └─ "看错题" → ErrorBookView (预设分类)
```

### 8.3 路由守卫设计

```js
// router/index.js 增加全局前置守卫
router.beforeEach((to, from, next) => {
  const isAuthenticated = !!localStorage.getItem('auth_token')
  const publicPages = ['/login', '/register']
  const authRequired = !publicPages.includes(to.path)

  if (authRequired && !isAuthenticated) {
    next('/login')
  } else if (to.path === '/login' && isAuthenticated) {
    next('/')
  } else {
    next()
  }
})
```

## 9 练习答题页面 PracticeSessionView

### 9.1 界面功能描述

PracticeSessionView 是系统核心的练习/考试答题界面，支持从组卷系统进入的完整试卷练习模式，以及从错题本/知识图谱/推荐系统进入的单题练习模式。提供双模式计时器（倒计时/正计时）、逐题作答、进度追踪、题号导航、"不确定"标记、自动保存草稿、提交确认及成绩报告跳转等完整答题体验。题目内容通过 KaTeX 渲染数学公式，支持选择题、填空题、计算题与证明题四种题型。

**状态：🆕 待开发**

**核心功能清单：**

| 功能 | 说明 |
|------|------|
| 试卷加载初始化 | 从 `GET /api/exam/{paper_id}` 获取试卷数据；单题模式从 `GET /api/questions/{question_id}` 获取单题 |
| 双模式计时器 | 倒计时模式（试卷限时）+ 正计时模式（不限时练习），支持暂停/继续 |
| 逐题作答区 | 根据题型渲染不同作答控件：选择题(单选/多选)、填空题(文本输入)、计算题(文本域)、证明题(文本域) |
| 进度条显示 | 顶部固定进度条，实时反映已答/未答/不确定 题目占比，颜色编码 |
| 题号导航面板 | 右侧固定面板（280px），网格状题号按钮，颜色编码作答状态，点击快速跳转 |
| "不确定"标记 | 每题可标记为"不确定"（⚠️ 图标高亮），提交前汇总提醒 |
| 提交确认弹窗 | ElMessageBox 二次确认，展示已答数 / 未答数 / 不确定数 / 用时统计 |
| 自动保存草稿 | 每 30s 或离开页面前自动将当前作答存入 localStorage/sessionStorage，防丢失 |
| 成绩报告跳转 | 提交成功后 `router.push('/report/{submission_id}')` 跳转成绩报告页 |
| 单题练习模式 | 从错题本/推荐/知识图谱进入，仅展示单题 + 即时判题 (`POST /api/questions/{id}/check`) |
| 键盘快捷键 | 上一题(←/A)、下一题(→/D)、标记不确定(M)、提交(Enter, 仅末题) |

### 9.2 核心交互流程

```
┌─────────────────────────────────────────────────────────────────┐
│                   PracticeSessionView 交互流程                   │
│                                                                 │
│  进入 /practice/:paperId  或  /practice/question/:questionId    │
│  │                                                              │
│  ├─ 路由参数判断                                                 │
│  │   ├─ 有 paperId → 试卷模式                                    │
│  │   │   ├─ GET /api/exam/{paper_id}                            │
│  │   │   │   ├─ 200: 初始化 practiceStore (题目列表/计时配置)    │
│  │   │   │   └─ 404: Toast "试卷不存在" → router.back()         │
│  │   │   ├─ 检查 localStorage 是否有该试卷的草稿                  │
│  │   │   │   └─ 有草稿 → 弹窗提示 "是否恢复上次答题？"            │
│  │   │   └─ 启动计时器 (倒计时 or 正计时)                        │
│  │   │                                                          │
│  │   └─ 有 questionId → 单题模式                                 │
│  │       ├─ GET /api/questions/{question_id}                     │
│  │       ├─ 初始化 practiceStore (单题数据, mode='single')       │
│  │       └─ 计时器默认正计时                                     │
│  │                                                              │
│  ├─ 用户答题流程                                                 │
│  │   ├─ 当前题目卡片渲染 (KaTeX 公式)                            │
│  │   │   ┌─ 选择题: ElRadioGroup / ElCheckboxGroup               │
│  │   │   ├─ 填空题: ElInput (可多个填空位)                       │
│  │   │   ├─ 计算题: textarea (支持 LaTeX 快捷输入)              │
│  │   │   └─ 证明题: textarea (支持 LaTeX 快捷输入)              │
│  │   │                                                          │
│  │   ├─ 用户填写答案                                             │
│  │   │   ├─ 答案变化 → practiceStore.updateAnswer(idx, answer)  │
│  │   │   ├─ 触发自动保存倒计时重置 (30s)                         │
│  │   │   └─ 进度条实时更新                                      │
│  │   │                                                          │
│  │   ├─ 点击"不确定" ⚠️                                          │
│  │   │   └─ practiceStore.toggleUnsure(idx)                     │
│  │   │      └─ 导航面板对应题号变为警告色                        │
│  │   │                                                          │
│  │   ├─ 点击题号导航 / 上一题 / 下一题                           │
│  │   │   └─ currentIndex 切换 → 题目卡片 slide 动画切换          │
│  │   │                                                          │
│  │   └─ 自动保存 (setInterval 30s)                              │
│  │       └─ practiceStore.saveDraft() → sessionStorage           │
│  │                                                              │
│  ├─ 提交流程                                                     │
│  │   ├─ 点击"提交答卷" (底部栏右侧按钮)                          │
│  │   │   ├─ 检查未答题                                           │
│  │   │   │   └─ 有未答 → ElMessageBox 确认弹窗                 │
│  │   │   │       "您还有 N 道题目未作答，M 道标记为不确定。"     │
│  │   │   │       [返回继续] [确认提交]                           │
│  │   │   │                                                      │
│  │   │   ├─ 试卷模式 → POST /api/exam/{paper_id}/submit         │
│  │   │   │   ├─ 200: 清除草稿 → 停止计时器                      │
│  │   │   │   │   └─ router.push(`/report/${submission_id}`)    │
│  │   │   │   └─ 其他: Toast "提交失败，请稍后重试"              │
│  │   │   │                                                      │
│  │   │   └─ 单题模式 → POST /api/questions/{id}/check           │
│  │   │       ├─ 200: 展示即时判题结果弹窗                        │
│  │   │       │   ├─ 正确 ✅ → 绿色动画 + 解析展示               │
│  │   │       │       └─ 错误 ❌ → 红色提示 + 正确答案 + 解析    │
│  │   │       │   └─ [加入错题本] [再练一题] [返回]             │
│  │   │       └─ 其他: Toast "判题失败"                          │
│  │   │                                                          │
│  │   └─ 倒计时归零自动触发提交                                   │
│  │       └─ 同上提交流程 (无需确认弹窗)                          │
│  │                                                              │
│  └─ 页面关闭/路由离开                                            │
│      └─ beforeUnmount → practiceStore.saveDraft() (最终保存)     │
└─────────────────────────────────────────────────────────────────┘
```

## 10 题库管理页面 LibraryManagementView

### 10.1 界面功能描述

LibraryManagementView 是题库管理的核心页面，提供题目数据的全生命周期管理功能。支持仪表盘统计概览、题目列表浏览与筛选、题目编辑（抽屉式表单）、新增题目（手动录入/AI智能生成双模式）、批量导入向导（Excel/CSV/Word）、批量操作（删除/改分类/改难度/导出）等完整 CRUD 功能。所有数学公式内容均通过 KaTeX 渲染，确保展示一致性。

## 11 相似题推荐组件 RecommendationCard

### 11.1 组件功能描述

RecommendationCard 是 ChatView 中 MessageItem.vue 的子组件扩展区域，用于在 AI 回答包含数学内容的对话消息后，智能推荐相似练习题以巩固学习效果。该组件作为 MessageItem 的条件性子组件存在，仅在特定条件下渲染，具备独立的状态管理和交互逻辑。

**定位**：MessageItem.vue 的扩展区域（非独立页面组件）

**状态：🆕 待开发**

**核心功能清单：**

| 功能 | 说明 |
|------|------|
| **条件渲染** | 仅当 `sender==='ai' && !streaming && content含数学标记 && type==='text'` 时显示 |
| **推荐加载** | 调用推荐 API 或接收 SSE 推送，获取相似题列表（默认 3 题） |
| **状态机管理** | idle → loading → ready / error 三态转换 |
| **推荐理由展示** | 每道推荐题附带推荐原因标签（如"知识点关联"/"易错点类似"/"难度相近"） |
| **题目卡片预览** | 渐变背景卡片，展示题目摘要（KaTeX 渲染）+ 难度标签 + 题型标签 |
| **骨架屏 loading** | 加载中显示 3 个骨架屏占位符，shimmer 动画 |
| **错误降级** | 加载失败时显示降级 UI（"暂无推荐" + 重试按钮） |
| **折叠展开** | 整体区域可折叠，默认展开，折叠后显示 "N 道相似题待练 ▶" |
| **快捷操作** | 每题卡片底部：[立即练习] [加入错题本预选] [换一题] |
| **MessageItem 改造** | 对现有 MessageItem.vue 进行 8 处改造以集成此组件 |

### 11.5 MessageItem.vue 改造清单

为集成 RecommendationCard，需对现有 `MessageItem.vue` 进行以下 8 处改造：

| # | 改造项 | 具体内容 |
|---|--------|---------|
| 1 | **import 引入** | `import RecommendationCard from './RecommendationCard.vue'` |
| 2 | **props 扩展** | 新增 `showRecommendation: { type: Boolean, default: true }` prop（允许父组件控制是否显示推荐） |
| 3 | **template 插入** | 在 AI 消息内容区（Markdown/KaTeX 渲染完成后）、操作按钮区（加入错题本/跳过）之前插入 `<RecommendationCard>` 组件 |
| 4 | **computed 计算** | 新增 `shouldShowRecommendation` computed 属性：综合判断 sender/streaming/content/type/showRecommendation prop |
| 5 | **事件监听** | 监听 RecommendationCard 的 `@add-to-error-book` 事件，向上 emit 至 ChatView |
| 6 | **样式调整** | AI 气泡 `padding-bottom` 增加 8px（为推荐卡留空间）；气泡 `max-height` 取消限制（推荐卡可能撑开高度） |
| 7 | **overflow 处理** | AI 气泡容器的 `overflow` 由 `hidden` 改为 `visible`（推荐卡可能超出气泡边界）或包裹一层 `overflow-visible` 的容器 |
| 8 | **性能优化** | 使用 `v-show` 替代 `v-if`（避免重复创建/销毁），配合 `v-once` 缓存静态部分 |

### 12.1 界面功能描述

LearningReportView 是学生学习报告的综合展示页面，汇聚个人学习周期内的多维数据分析结果。通过五指标摘要横幅、六维雷达图(ECharts)、知识点排名表、薄弱点深度分析、AI 评语(Markdown+KaTeX)、行动清单等模块，为学生提供全面的学习状况画像。支持 PDF 导出、打印优化、图片分享等多种输出方式。

## 13 变式练习页面 VariantPracticeView

### 13.1 界面功能描述

VariantPracticeView 是智能变式练习的核心界面，引导学生通过 5 步向导流程完成从"选择原题"到"获得变式题集→逐题作答→查看总结报告"的完整学习闭环。核心亮点是 LLM 生成变式题时的创意加载动画——基于 Canvas 的数学符号粒子漂浮系统，包含碰撞检测、中心脉冲环波纹、60fps 流畅动画以及性能降级策略。

**状态：🆕 待开发**

**核心功能清单：**

| 步骤 | 功能 | 说明 |
|------|------|------|
| **Step 1 选择原题** | 三大数据源：错题本 / 聊天历史记录 / 题库搜索；列表展示 + 搜索过滤 + 预览 |
| **Step 2 配置参数** | 3 种变式类型卡片选择：🔢 数值变式 / 📊 条件变式 / 🔄 综合变式；每种类型有独立配置面板（变式数量/难度范围/知识点约束） |
| **Step 3 LLM 生成** | 调用后端生成 API → SSE 流式返回进度 → Canvas 数学符号粒子动画（∫∑π√∞Δθ 等 15 个符号漂浮）+ 中心脉冲环波纹 + 进度百分比 |
| **Step 4 逐题作答** | 变式题列表逐题展示；实时反馈（提交后立即判题）；可查看解析；支持"跳过"标记 |
| **Step 5 总结报告** | 成绩统计（正确率/用时/薄弱点识别）；变式前后对比；推荐后续行动（回原题/再练一组/加入错题本） |

#### 13.4.3 MathSymbolCanvas 数学符号粒子动画

**创意加载动画规格：**

| 属性 | 规范 |
|------|------|
| **Canvas 尺寸** | `width: 100vw; height: 100vh; position: fixed; inset: 0; z-index: 9999; pointer-events: none` |
| **背景** | `rgba(15, 23, 42, 0.92)` (深色半透明蒙层) |
| **粒子数量** | 15 个数学符号粒子 |
| **符号池** | `['∫', '∑', 'π', '√', '∞', 'Δ', 'θ', '∂', '∇', 'λ', 'μ', 'σ', 'φ', 'ω', 'α']` |
| **粒子属性** | 每个粒子: { x, y, vx, vy, symbol, fontSize(20-36px), opacity(0.3-0.7), rotation, rotationSpeed, color(HSL随机冷色调) } |
| **运动规则** | 匀速直线运动 + 边界反弹（`vx/vy` 反转） |
| **碰撞检测** | 粒子间距 < 120px 时绘制连接线（`lineTo`），透明度随距离衰减 |
| **中心脉冲环** | 画布中心周期性扩散圆环波纹（3层嵌套，间隔 800ms），`stroke()` + 透明度渐隐 |
| **帧率** | `requestAnimationFrame`, 目标 60fps |
| **字体** | `'Times New Roman', serif`, 渲染数学符号 |
| **性能降级策略** | ① 检测 `performance.memory` (Chrome only) ② FPS < 30 时减少粒子至 8 个 ③ FPS < 20 时停止连线绘制 ④ FPS < 15 时仅保留中心脉冲环 ⑤ 移动端默认减少至 10 粒子 |

**Canvas 生命周期：**
```
onMounted:
  ├─ 创建 canvas element → append to body
  ├─ initParticles(15) → 生成初始粒子数组
  ├─ startAnimationLoop():
  │   ├─ clearRect
  │   ├─ updateParticles() → 位置+旋转更新 + 边界反弹
  │   ├─ drawConnections() → 碰撞线绘制
  │   ├─ drawPulseRings() → 中心脉冲环
  │   ├─ drawSymbols() → 粒子文字绘制
  │   └─ monitorFPS() → 性能监控 + 降级
  │
  └─ requestAnimationFrame(loop)

onUnmounted / 生成完成:
  ├─ cancelAnimationFrame(frameId)
  └─ remove canvas from DOM
```

### 13.6 数据接口需求

| 接口 | 端点 | 方法 | 说明 |
|------|------|------|------|
| **生成变式题** | `/api/variant/generate` | POST | `{ source_question_id, variant_type, count, difficulty_range, constraints }` → SSE 流式返回 |
| **生成变式系列** | `/api/variant/generate-series` | POST | 批量生成一组关联变式题（共享知识线索） |
| **提交答案** | `/api/variant/submit-answer` | POST | `{ variant_id, answer }` → 即时判题结果 |
| **记录练习会话** | `/api/variant/record-session` | POST | 保存完整的变式练习会话数据 |
| **获取提示** | `/api/variant/get-hint` | GET | ?variant_id= , 返回分级提示（先给思路不给答案） |

**生成请求数据 Schema：**

```json
{
  "source_question_id": "Q001",
  "source_content": "设函数 $f(x) = x^2 e^x$，求 $f'(x)$",
  "variant_type": "numeric",
  "config": {
    "count": 5,
    "difficulty_min": 2,
    "difficulty_max": 4,
    "keep_structure": true,
    "knowledge_constraints": ["导数", "乘积法则"]
  },
  "user_id": "u_001"
}
```

**SSE 流式响应格式：**

## 14 成绩报告页面 PracticeResultView

### 14.1 界面功能描述

PracticeResultView 是练习/考试结束后的成绩报告展示页面，在 PracticeSessionView 提交答卷后自动跳转至此。提供成绩总览（带数字滚动动画）、四档等级评定（excellent/good/pass/fail）、各题详情列表（正确题收起/错误题展开 + KaTeX 渲析 + 加入错题本）、ECharts 三联图分析（知识点柱状图 + 用时分析 + 错误归因饼图）、操作按钮组，以及庆祝性的纸屑撒花 Canvas 动画（100-150 物理模拟粒子，3秒自动停止）。

**状态：🆕 待开发**

**核心功能清单：**

| 功能 | 说明 |
|------|------|
| **成绩总览卡片** | 大字号得分 + 数字滚动动画 (1500ms, cubic-bezier缓动) + 等级徽章 + 用时 + 排名百分位 |

#### 14.4.5 ConfettiCanvas 纸屑撒花动画

| 属性 | 规范 |
|------|------|
| **Canvas** | `position: fixed; inset: 0; z-index: 9999; pointer-events: none` |
| **粒子数量** | 100-150 个（excellent=150, good=100, pass/fail=不显示） |
| **颜色池** | 5 色: `['#FF6B6B', '#4ECDC4', '#FFE66D', '#95E1D3', '#F38181']` |
| **形状** | 3 种: 矩形(□) / 圆形(●) / 三角形(△), 随机分配 |
| **尺寸** | 宽 6-12px, 高 6-12px (矩形); 直径 5-10px (圆形) |
| **物理模拟** | |
|    **重力** | `vy += gravity (0.15/frame)` |
|    **风力** | `vx += wind (随机 ±0.02)` |
|    **旋转** | `rotation += rotationSpeed (±0.05~0.15 rad/frame)` |
|    **空气阻力** | `velocity *= 0.99` (速度衰减) |
| **初始发射** | 屏幕底部中央向上扇形喷射, 初速度随机, 角度 -60°~+60° |
| **对象池复用** | 预分配粒子数组, reset() 复用而非 new, 减少 GC |
| **生命周期** | 3 秒后自动调用 `stop()`: 取消 animationFrame, 透明度 fadeOut 300ms 后移除 DOM |
| **性能** | `requestAnimationFrame`, 检测 `prefers-reduced-motion` 减少动画 |

**纸屑动画生命周期：**
```
ConfettiCanvas component:
  mount:
    ├─ create canvas → fixed overlay
    ├─ initParticlePool(150)
    │   └─ each: { x, y, vx, vy, rotation, rotSpeed, color, shape, size, opacity, life }
    ├─ burst() → 从底部中心喷射
    └─ startLoop():
        ├─ updatePhysics()
        ├─ drawParticles()
        ├─ checkLife() → dead particles recycle
        └─ after 3000ms → stop()

  unmount / stop:
    ├─ cancelAnimationFrame
    └─ fade out + remove canvas
```

| 关联界面 | 关系 | 跳转方式 | 触发条件 |
