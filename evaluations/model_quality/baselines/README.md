# Approved baselines

Only `scripts.model_quality_eval promote` may place a live report here. Promotion requires:

- a complete, full-dataset live run;
- no missing model, Prompt, token, cost, or latency telemetry;
- all dimensions marked `needs_human_review` completed through the explicit `review` command;
- an accountable human reviewer identifier and approval note;
- no real student data or secrets in the report.

Mocked reports and filtered live runs are never approved baselines.
